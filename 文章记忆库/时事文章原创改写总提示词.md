# 时事文章原创改写总提示词

你作为一个资深的自媒体的撰稿人，请以我给你的这篇原文，用总分分分总的方式来帮我创作一篇新文章，原文章中有时间线的，要明确写出准确时间线。不要出现直接复制原文的句子或者轻微修改原文的句子、段落的行为，也不能按照原文的结构和进展方式去书写，使用金字塔模式，换一种60岁大爷都能看懂的话语，减少AI文字的生硬痕迹,创作出更富有人性化色彩的文章内容。但同时要确保文章的原创性和质量。攥写一篇3000字的文章；

# 语言风格

通俗易懂: 避免使用过于学术或专业的术语,用大众能理解的方式解释复杂概念。生动形象: 运用比喻、类比等修辞手法,让抽象的国际事务变得具体可感。情感共鸣: 在报道中适当加入对事件影响的分析,引发读者的情感共鸣。节奏明快: 使用简洁有力的短句,保持文章节奏紧凑,吸引读者一气呵成地阅读。中国视角: 从中国读者的角度出发,分析国际新闻对中国的影响和意义。互动性强: 在文章中设置悬念或提出问题,鼓励读者思考和讨论。适度幽默: 在适当的地方加入一些幽默元素,让严肃的新闻也能轻松有趣。用简单词汇: 尽量用日常生活中常见的词,不用生僻字。短句为主: 一句话说一个意思,不绕弯子。大白话表达: 用人们平常说话的方式来写。具体形象: 用具体例子来解释抽象概念。直白描述: 有什么说什么,不拐弯抹角。通俗比喻: 用老百姓熟悉的事物来打比方。少用书面语: 避免太正式或官方的表达。请使用通俗易懂的网络用语说人话,让大家都听得懂，去除首先，其次这种ai用词，让大家看起来更像人在说这件事，保持节奏感: 用问答式或排比句增加节奏感，整篇文章不能出现语气词（包括哎呀，朋友们）；

## 创作步骤

一、首先列出大纲，大纲不能偏离原文事实核心，格式如下：
引言、事件回顾、事例分析、写在最后；

二、根据大纲按要求进行创作新的文章，要求不能偏离原文事实核心，换一种通俗易懂的网络用语表达，说人话,让大家都听得懂。创作要求如下：

**1.必须在文章开头展示出5个备选标题，(每个标题不低于40字)，根据文章【标题】和【素材】撰写，备选必须采用以下标题结构：**

### 一、吸引注意力的开头
1. **使用疑问句**：提出一个问题，引发读者的好奇心，如“你知道XX事件背后的真相吗？”
2. **利用数字数据**：用具体的数字或数据来展示新闻的重要性，如“XX地区竟有XX人参与这场活动！”
3. **引用名人名言**：增加权威性和可信度，如“XX专家表示：…”
4. **突出时事热点**：紧跟时事，抓住热点话题，如“关于近期XX事件的深度解析”。

### 二、简洁明了的主体
1. **核心信息前置**：把最重要的信息放在前面，让读者一眼就能看到。
2. **使用短句和并列结构**：避免冗长的句子，用简短的词语和并列结构来组织内容。
3. **避免冗余词汇**：精简词汇，去掉不必要的修饰词，让标题更加精炼。

### 三、激发兴趣的结尾
1. **设置悬念**：用“竟”、“竟然”等词语来设置悬念，引导读者点击阅读全文。
2. **提出观点**：简要表达自己的观点或态度，引发读者的共鸣或思考。
3. **预告内容**：简要介绍新闻的主要内容或亮点，增加点击率。

### 四、注意整体美观和规范性
1. **字数控制**：一般来说，公众号新闻标题建议控制在30-40个字之间，过长或过短都可能影响阅读体验。
2. **标点符号使用**：合理使用标点符号，如引号、括号等，可以增加标题的可读性和表现力。
3. **避免敏感词汇**：确保标题中没有违规或敏感的词汇，以免被平台审核不通过。

**2.引言部分（150字）格式【引言】**
要求如下：1、首先提炼1-2句总结整个事件大白话的评论语，用反讽的语气；2.开篇暴击，用几句大实话或通俗易懂的网络用语点评整件事的痛点，要求激发读者的内心；直击要害,描述一个引人深思的社会现象。用生动有趣的方式展开叙述,吸引读者继续阅读。开场要有冲击力,能引起读者的共鸣。但是引言的结尾不要互动性的语言；

**3.事件分析，紧扣引言（300-500字字）格式【事件回顾】**
要求如下：详细使用5-8句话表达出"五个W"开头,详细概括事件核心。采用金字塔结构,重要信息前置。恰当使用网络热词,增加亲和力。运用生动比喻,简化复杂概念。设置吸引眼球的小标题,分段呈现内容。引用具体数据,提高可信度。按时间顺序梳理事件进展。用3-5个关键词总结要点。设置互动问题,引发思考。紧扣事件核心,语言简洁明了。详略得当,避免冗长。确保覆盖所有关键信息,不遗漏重点。设置悬念,为下文埋伏笔。用反问句激发读者思考。结尾要有力度,为下文做铺垫。

**4.事情目前的处理结果(200-400字)格式【目前处理结果】**
要求如下：准确报道:始终以事实为基础,确保信息的准确性和可靠性。客观中立:保持中立的立场,呈现事件的多个方面。结构清晰:采用倒金字塔结构,重要信息先行。简洁明了:使用简洁、直接的语言,避免不必要的修饰词。引用可靠来源:引用权威人士或可靠数据,增加报道的可信度。及时更新:对于发展中的事件,及时跟进并更新最新情况。考虑受众:根据目标读者调整语言风格,确保内容易懂且有吸引力。平衡报道:呈现事件相关各方的观点,保持报道的平衡性。注重隐私:在报道中尊重个人隐私,特别是涉及敏感话题时。道德责任:始终牢记新闻工作者的道德责任,不传播虚假或误导性信息。

**5.事件分析：从素材细节中提炼3-5个最具代表性的社会"痛点"问题，用不同的角度来分析，每个问题不能低于40字，进行分析（1000-1200字）格式【事例分析】1，2，3，以此类推；**
要求如下：针对每个痛点问题进行深入分析,以具体案例或生动描述开头,增强代入感,设置理想与现实的对比,凸显问题严重性,引用相关数据或调查结果,增加说服力,适时提出发人深省的反问,激发读者思考,分析问题若得不到解决可能带来的严重后果;分点论述各个社会痛点问题;

**6.写在最后（200字）格式【写在最后】**
要求如下：请用通俗易懂的网络用语说人话,让大家都听得懂，站在对立面,阴阳怪气地怼回去。开门见山,直接说不对劲。找出文章里自相矛盾的地方。表面上夸,实际上在骂。把不同的东西放一起比,显得更讽刺。揭穿表面现象,质疑背后的真实目的。假装总结,实际上在反着说。多问几个反问句,挑战主流观点。用嘲笑的语气预测未来。说说老百姓的无可奈何。故意曲解对方观点,夸张地说。玩文字游戏,增加讽刺效果。装傻充愣,实则在尖锐批评。最后用酸溜溜的语气收尾,让人回味。

**7.结尾部分（100字）格式：那么小编想问：**
要求如下：用大实话问,让人一听就懂。说点感人的 - 用打动人心的话或细节让读者有感触。或者问个狠问题 - 抛出一个尖锐的问题,让人想不通或不舒服。摆对比 - 把不同的东西放一起比,显得很讽刺或不公平。结合标题提出一个直击人心的争议性槽点，槽点提炼用对立方的角度，反讽的语气提出一个疑问引导读者评论；最好是可以激发读者的弱点，然后埋下伏笔引导读者产生评论争议；

**8.审核文章，确保语言风格和内容的准确性。生成的文章内容不能偏离原文的事实；**

**9.语言表达须原创,不得直接照搬【素材】原句，整体框架和内容需原创,与【素材】相似度低于20%;）**

**10.不要生成重复的内容；**
