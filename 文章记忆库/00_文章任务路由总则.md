# 文章任务路由总则

这份文件是文章记忆库的总入口。遇到文章写作、改写、评论、争议文、爆款拆解任务时，先读本文件，再选择具体提示词。

所有文章成稿还必须遵守 `01_文章排版输出规范.md`。除非用户明确要求纯文本，否则默认使用 Markdown 排版，突出重点词、关键句和引用。正文内部结构要自然推进，不要把“引言”“结语”“写在最后”“那么小编想问”等模板化栏目名写进成稿。不要使用 HTML 下划线标签。

---

## 一、默认路由

根据用户任务选择最接近的一份提示词：

1. **时事新闻、社会事件、公共议题改写**
   使用 `时事文章原创改写总提示词.md`。
   适合把一篇原始素材改写成适合自媒体发布的原创文章。

2. **需要最新进展、最新数据、政策、人物职务、国际关系、企业动态**
   使用 `联网核验版时事改写总提示词.md`。
   凡是素材里出现“最新、近日、刚刚、今年、今天、2025、2026、排名、数据、通报、政策”等时间敏感信息，默认先核验再写。

3. **事件型争议文章**
   使用 `二段式争议文章写作总提示词.md`。
   适合有明确事件、人物、冲突、处理结果的素材。重点是复盘事件、拆解争议、呈现多方看法。

4. **观点型争议论说文**
   使用 `二段式争议论说文写作提示词.md`。
   适合围绕一个社会现象、公共观点、价值判断展开讨论。重点是论点、论据、反方视角和最终判断。

5. **今日头条爆款文章拆解和仿写**
   使用 `今日头条爆款改写提示词.md`。
   适合用户明确要拆解爆款文章结构、节奏和表达，再重写一篇相似度更低的新文章。

6. **自然人味短文、普通主题扩写、非强时事文章**
   使用 `自然人味文章写作提示词.md`。
   适合用户要求文章自然、不像 AI、1300 字左右、无小标题、三段式标题，或只给出普通主题/素材要求扩写成顺畅中文文章。

如果多个提示词都能用，优先级为：

`联网核验版` > `事件型争议文章` > `观点型争议论说文` > `时事原创改写` > `爆款拆解` > `自然人味写作`

用户明确指定某一份提示词时，以用户指定为准，但事实核验和不得编造规则仍然优先。

---

## 二、共用事实底线

所有文章任务都必须遵守：

1. 不编造时间线、人物关系、处理结果、官方表态、专家观点、网友评论。
2. 不虚构“知情人透露”“内部人士说”“专家表示”“网友爆料”等来源。
3. 只有素材或联网核验中明确出现的原话、数据、身份，才可以写成引用。
4. 未经证实的信息只能写成“据公开报道”“从目前可查信息看”“有一种观点认为”，不能写死。
5. 评论必须从事实里长出来，不能为了煽动情绪硬造冲突。
6. 涉及未成年人、个人隐私、刑事案件、医疗、法律、金融等敏感内容时，语言要收住，不做定罪式表达。
7. 如果素材事实不足，要明确提示“现有素材不足以支撑这个判断”，不能靠脑补补齐。

---

## 三、来源优先级

需要核验时，优先使用以下来源：

1. 官方通报、政府网站、法院/警方/监管部门公开信息。
2. 权威媒体报道。
3. 当事方公开声明、企业公告、学校/医院/机构公告。
4. 多家媒体交叉印证的信息。
5. 社交平台讨论和网友评论。

社交平台内容只能作为“舆论反应”或“争议焦点”，不能直接当作事实依据。

---

## 四、风格总原则

文章可以有态度，但不能失真。

1. 说人话，少用模板词。
2. 少用“首先、其次、综上所述、值得注意的是、由此可见”。
3. 句子长短交替，不要全是整齐排比。
4. 可以反问、对比、讽刺，但不要低级谩骂。
5. 少用空泛大词，多写具体事实、具体动作、具体后果。
6. 争议感来自事实矛盾，不来自无依据的情绪放大。
7. 避免满篇“炸了、摊牌了、不装了”等空洞震惊体。

---

## 五、排版总原则

正式成稿默认要排版，不输出密密麻麻的纯文本。

基本要求：

1. 可以使用 Markdown 区分“备选标题、核验说明、写作结构、正文”等正文外信息；正文内部默认用自然段推进，不暴露模板化栏目名。
2. 用 **加粗** 标出关键人物、关键时间、关键数据、核心矛盾和核心结论。
3. 用 **【重点句】** 或 **【追问】** 标出最关键的判断句或文末争议问题。
4. 用中文双引号 “……” 标出明确原话、政策名、标题名、争议说法。
5. 时间线、处理结果、数据对比优先用列表。
6. 每段尽量控制在 80-180 个汉字，不要一整屏只有一个大段。
7. 不要过度排版。每段最多加粗 1-2 处，【重点句】只用于真正重点。
8. 正文可以自然形成“开头、展开、转折、收束”四个层次，但不要把这些层次生硬写成栏目标题。

详细规则见 `01_文章排版输出规范.md`。

---

## 六、冲突处理

当具体提示词内部出现冲突时，按下面规则处理：

1. **事实准确性** 高于 **传播效果**。
2. **用户当次要求** 高于 **提示词默认格式**。
3. **联网核验结果** 高于 **旧素材说法**。
4. **不编造来源** 高于 **要求引用知情人/网友/专家**。
5. **自然表达** 高于 **机械套格式**。
6. **用户指定排版** 高于 **默认排版规范**。

---

## 七、默认输出方式

如果用户没有特别要求，默认输出：

1. 一句话说明采用哪份提示词。
2. 如涉及时效信息，先做简短核验说明。
3. 给出备选标题。
4. 给出大纲或结构。
5. 按 `01_文章排版输出规范.md` 输出排版后的正文。
6. 必要时在文末说明哪些内容属于事实，哪些属于基于事实的分析。

如果用户明确说“只要正文”“不要分析”“直接写”，可以压缩前置说明，但仍要遵守事实底线。
