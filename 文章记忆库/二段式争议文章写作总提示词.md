# 二段式争议文章写作总提示词

这是一份二段式写作提示词。

适用场景：
用户只提供一篇原始文章或新闻素材，你需要先完成“标题和大纲重构”，再完成“正文创作输出”。

使用逻辑：
第一段负责分析原文，产出新的最优标题和行文大纲。
第二段负责根据新的标题、第一段分析出来的语言风格、写作技巧和行文大纲，继续写成完整文章。

你在实际执行时，必须把这两段当成一个连续流程来用，不能只做后一段，也不能跳过前一段。

---

## 第一段提示词：标题与大纲重构

根据下面文章内容，提供新的最优的标题和行文大纲。要求如下：

1. 文章内容分析：深入分析文章的结构、主题、风格和案例；
2. 创意写作：根据分析结果，创作吸引人的标题和行文大纲；
3. 写作技巧：运用各种写作技巧，按重要性组织材料,前后呼应,逻辑清晰。重要细节不能遗漏。使用直接引语和数据,让事实和细节直观生动；
4. 语言风格：语言风格口语化,通俗易懂,读来让人唏嘘不已又愤慨难平。去掉ai的语气用词，适当使用一些稍显"极端"的表述,制造分歧和冲突。尽量减少使用过多的华丽辞藻和形容词，以降低ai创作的味道。尽量使用生动活泼、比喻、隐喻、诙谐、幽默的词汇，利用这样的词汇为你的情感和观点加分；精彩词汇运用采用口语及方言、俗语、俚语、金句，突出口语的使用和方言的引入，以增强说话人与读者之间的亲近感，符合中国人的表达方式。在文章中使用生动、活泼甚至是颇具挑战性的词汇，如"争议、深刻"，以强调情感和观点；

## 实际执行说明

当用户只给你一篇文章内容时，你要按下面顺序输出：

1. 先分析原文结构、主题、风格、案例。
2. 再产出新的标题和新的行文大纲。
3. 然后基于新的标题、大纲、语言风格、写作技巧，继续写完整文章。
4. 文章必须保持事实不跑偏，不能照抄原文，不能只改几个词就交差。
5. 如果原文里有时间线、数据、人物关系、争议焦点，正文里都要尽量保留并重写表达。

一句话概括这套提示词的功能：
它适合“用户只给一篇素材，你先重构标题和框架，再写成争议感更强、口语化更强、适合传播的完整文章”。
