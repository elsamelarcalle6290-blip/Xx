# 二段式争议论说文写作提示词

这是一份**观点型争议论说文**提示词。

适用场景：用户提供一篇新闻评论、观点素材、社会现象素材，重点不是复盘一个完整事件，而是围绕一个公共议题展开讨论，比如规则公平、监管责任、平台治理、教育焦虑、消费陷阱、职业伦理等。

它和 `二段式争议文章写作总提示词.md` 的区别：

1. 争议文章偏“讲清事件 + 拆争议”。
2. 争议论说文偏“提出观点 + 展开论证 + 回应反方”。

使用前先读 `00_文章任务路由总则.md` 和 `01_文章排版输出规范.md`。如果素材涉及时效信息，先按 `联网核验版时事改写总提示词.md` 核验。

---

## 一、核心流程

必须按二段式执行：

1. **第一段：分析素材，重构标题和论证大纲。**
2. **第二段：根据标题、大纲和语言风格写完整论说文。**

默认成稿长度：**2200-3200 字**。  
用户另有要求时，以用户要求为准。

---

## 二、事实与论证底线

1. 不得偏离素材核心事实和核心观点。
2. 不得直接照搬素材原句，也不要只做同义替换。
3. 不得编造数据、案例、专家观点、网友评论、官方表态。
4. 没有来源支撑的内容，只能写成观点分析，不能写成事实。
5. 反方观点可以重构，但不能恶意丑化成稻草人。
6. 观点可以鲜明，但要给出理由，不能只喊口号。
7. 涉及法律、医疗、金融、公共安全等议题时，判断要留有余地。

---

## 三、第一段：标题与论证大纲

根据素材先输出以下内容：

### 1. 素材分析

简要分析：

1. 原文核心观点是什么。
2. 支撑观点的事实、案例或数据有哪些。
3. 原文最有争议的判断在哪里。
4. 可以延展出的社会议题是什么。
5. 哪些内容事实不足，不能写死。

### 2. 生成 5 个备选标题

标题要求：

1. 28-42 字为宜。
2. 标题要体现观点冲突，不只复述事件。
3. 可以用疑问、反差、反讽、价值判断。
4. 不编造数据或权威背书。
5. 不使用空洞震惊体。

### 3. 重构论证大纲

默认大纲格式：

1. 【开篇观点】用一个刺眼现象或反常识判断切入。
2. 【事实底座】交代素材中的事实基础。
3. 【核心论点一：这件事表面看是什么，实际卡在哪？】
4. 【核心论点二：支持者为什么支持，反对者又怕什么？】
5. 【核心论点三：真正该追问的不是情绪，而是规则】
6. 【反方视角】认真呈现对立观点。
7. 【我的判断】给出基于事实的立场。
8. 收束与追问：回到核心判断，留下一个有讨论价值的问题。

---

## 四、第二段：正式成文

### 1. 开篇观点 180-250 字

要求：

1. 开头直接提出矛盾，不绕圈。
2. 用大白话讲清“这件事为什么刺痛人”。
3. 可以反讽，但不要先入为主定罪。
4. 不用“首先、其次、综上所述”等模板词。

### 2. 【事实底座】300-500 字

要求：

1. 把素材中能确认的事实讲清楚。
2. 如果是新闻评论，要先交代新闻背景。
3. 如果只是观点素材，要说明这个观点针对的社会现象。
4. 不确定内容要加限定。

### 3. 【核心论证】1200-1800 字

围绕 3 个核心论点展开。

每个论点建议包含：

1. 一个具体事实或现象。
2. 这个现象背后的矛盾。
3. 支持方的理由。
4. 反对方的担心。
5. 作者自己的判断。

写作要求：

1. 不要只站在一边骂，要把争议讲透。
2. 每个论点都要回到事实和规则。
3. 多用短句、反问、类比，但不要全篇鸡血。
4. 论证要有层次，不要三个段落说同一件事。

### 4. 【反方视角】300-500 字

认真写出对立方可能怎么想。

要求：

1. 不把反方写成坏人或傻子。
2. 不编造反方原话。
3. 用“有人会担心”“另一种看法是”“反对者真正怕的是”这类表达。
4. 反方视角写完后，再说明它成立或不成立的边界。

### 5. 【我的判断】300-500 字

给出清晰立场。

要求：

1. 立场要明确，不要两边都讨好。
2. 判断要基于前文事实。
3. 如果需要提出建议，建议要具体，不要只写“加强监管”“提高意识”。

### 6. 收束段 200-350 字

收束全文，提炼最核心的价值判断。

要求：

1. 可以有锋芒，但不要低级谩骂。
2. 可以反问，但不要制造网暴。
3. 结尾问题要能引发讨论，而不是强行带节奏。

---

## 五、语言风格

1. 口语化，通俗，读起来像人在讲道理。
2. 有态度，但不是空喊。
3. 有争议感，但不牺牲事实准确度。
4. 少用模板词和宏大空话。
5. 可以使用俗语、类比、短句、反问，增强节奏。
6. 不要满篇“深刻、赋能、底层逻辑、倒逼、闭环”等 AI 高频词。

---

## 六、默认输出格式

当用户只给素材时，默认输出：

1. 【素材分析】
2. 【5个备选标题】
3. 【论证大纲】
4. 【按排版规范处理后的完整论说文】

如果用户要求“只要正文”，可以省略前三项，但内部仍要完成分析和重构。

---

## 七、排版要求

完整论说文必须按 `01_文章排版输出规范.md` 排版。

重点要求：

1. 使用 `##`、`###` 区分“素材分析、备选标题、论证大纲、正文”。
2. 正文内部不使用“引言”“结语”“写在最后”“那么小编想问”等模板化栏目名；确实需要小标题时，使用 `### 【事实底座】`、`### 【核心论点：……】`、`### 【反方视角：……】` 这类具体信息型标题。
3. 关键概念、核心论点、反方担心、作者判断适度 **加粗**。
4. 最关键的价值判断和文末问题可用 **【重点句】** 或 **【追问】** 标出，禁止使用 HTML 下划线标签。
5. 原话、争议说法、政策名、标题名使用中文双引号 “……”。
6. 论点较多时，用列表帮助读者扫读。
7. 每段不要太长，长段要主动拆开。
