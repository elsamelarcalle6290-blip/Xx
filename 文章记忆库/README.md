# 文章记忆库

这个文件夹用于存放后续可复用的文章写作提示词。遇到文章改写、新闻评论、争议文、爆款拆解等任务时，先看 `00_文章任务路由总则.md`，再选择具体提示词。正式成稿默认还要遵守 `01_文章排版输出规范.md`。

## 当前文件

1. `00_文章任务路由总则.md`
用途：作为总入口，负责提示词路由、事实底线、来源优先级、风格总原则和冲突处理。

2. `01_文章排版输出规范.md`
用途：统一文章输出排版，规定标题区、正文小标题、重点加粗、关键句自然突出、中文双引号、时间线列表和段落长度等规则。禁止使用 HTML 下划线标签。

3. `3000字总分式爆款改写提示词.md`
用途：文章改写首选提示词。用于把原文或素材改写成 3000 字左右、总分式结构、时间线清楚、大白话、低AI味、原创度高的爆款长文。成稿不露出“引言”“写在最后”“那么小编想问”等模板栏目名。

4. `时事文章原创改写总提示词.md`
用途：用于把原始新闻或公共事件素材改写成 2200-3000 字左右、适合自媒体发布的原创文章。

5. `二段式争议文章写作总提示词.md`
用途：适合事件型争议文章。先分析素材并重构标题、大纲，再围绕事件经过、争议焦点、多方观点和结尾发问写成完整文章。

6. `二段式争议论说文写作提示词.md`
用途：适合观点型争议论说文。先分析素材并重构标题、大纲，再围绕社会现象、核心论点、反方视角和个人判断写成完整文章。

7. `今日头条爆款改写提示词.md`
用途：用于分析今日头条爆款文章的结构、节奏和表达方式，再输出一篇相似度更低、但保留核心观点的新文章。

8. `自然人味文章写作提示词.md`
用途：用于普通主题扩写、非强时事文章、自然口语化文章和 1300 字左右直接正文成稿。重点是减少模板腔、控制事实边界、让文章更像真实作者写出来。

## 共用底线

所有提示词都必须遵守：

1. 不编造时间线、人物关系、官方表态、专家观点、知情人爆料、网友评论。
2. 只有素材或事实核验中明确出现的内容，才可以写成直接引用。
3. 事实准确性优先于传播效果。
4. 争议感来自事实矛盾，不靠谩骂、夸张和未经证实的信息制造冲突。
5. 成稿必须按排版规范输出，除非用户明确要求纯文本。
