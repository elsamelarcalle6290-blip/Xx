# 百家号文章记忆库

这个文件夹用于存放百家号财经内容的长期写作提示词和后续可复用资料。

当前主要文件：

1. `百家号写作总提示词.md`
用途：后续持续写百家号财经文章时优先调用的统一提示词

2. `今日头条写作总提示词.md`
用途：后续持续写今日头条财经文章时优先调用的统一提示词

3. `今日头条微头条写作提示词.md`
用途：后续持续写今日头条财经微头条时优先调用的统一提示词

建议使用方式：

1. 以后新增百家号财经文章时，优先基于“百家号写作总提示词”继续生成
2. 如果账号风格发生变化，只改提示词，不要反复堆积整篇文章到记忆库
3. 如果出现新爆款方向，就把新规则补进提示词，而不是单独记很多篇原文
