# 当前聚焦

## 当前重点（第31章开始）

### 核心冲突
楚妄、陈远、小鹿、沈墨渊暂避无名村祠堂。雪符追名被无名牌位吞噬，但祠堂铜片保存了沈墨渊旧名，并留下“若他护你，先斩其名”的警告。楚妄的名字也开始在空牌位上浮现，说明无名村不是避风港，而是天道修正机制留下的更深入口。

### 已确认的设定
1. **道果三层结构**：壳（夜红莲手里的空壳）、肉（散落世界各处）、核（楚妄神魂里，与黑莲共存）
2. **夜红莲的困境**：她已经察觉两半玉佩合一也只是空壳，正追楚妄与道果之肉
3. **楚妄的终极困境**：要完整道果就得释放神魂里的核，直接取出核=死
4. **沈墨渊钩子**：旧名被无名村保存，天道可能准备先斩其名来牵制楚妄
5. **无名村**：能吞噬名字，也会显露旧修正痕迹
6. **苏清寒追名**：因果榜已显楚妄姓名，霜华暗中延缓雪符但拖不了太久

### 待解决的问题
1. 无名村为何保存沈墨渊旧名？
2. 霜华会如何撕开苏清寒的记忆裂缝？
3. 苏清寒崩溃前会先出现什么失衡征兆？
4. 沈墨渊何时被天道正式激活？
5. 楚妄如何在保护沈墨渊与斩断因果之间做选择？
6. 两块道果之肉如何继续保存，避免被黑莲和天道牵动？

### 第31章写作抓手
- 无名村祠堂余压仍在，先写楚妄稳伤、稳人、稳局。
- 霜华必须开口，但不能一次性讲完全部前世。
- 苏清寒不能立刻洗白或倒向楚妄，只写记忆裂缝扩大和情绪失衡前兆。
- 楚妄的反应必须是先算风险，再判断霜华话里的证据价值。
