# 当前聚焦

## 当前重点（第46章开始）

### 核心冲突
楚妄一行已进入不可知之地，外部追踪暂时被切断，但此地会主动观测、记名和预先留下脚印。魔渊线确认灰袍不是此界之物，所谓天道更像外来寄生物；顾青鸾正在被修正，证据靠错字和脏账继续扩散。第46章应转向霜华，让她在苏清寒封锁出口时做第二次选择。

### 已确认的设定
1. **强行突破代价**：楚妄只打开筑基一线，不是完整升级；左耳失聪、十年寿元、名字裂一笔、肩骨雷伤和丹田新裂必须保留。
2. **不可知之地规则**：它隔绝外部追踪，但会记住入内者；脚印可能先于行动出现，血会被记录，假熟人会诱人回头，石碑会标记“已入，待观”。
3. **老周锚点**：老周疑似被修正，但错字欠条和裂口酒杯仍能作为凡人见证锚点。
4. **顾青鸾代价**：她不是一次性失忆，而是师父姓名、暗河初衷和自身身份开始混淆；错字证据能短暂抗修正。
5. **魔渊情报**：墨殇查到灰袍衣角不属于此界，夜红莲通过红莲令牌把“天道可能是外面来的东西”送给楚妄。
6. **沈墨渊风险**：旧名钩子未清，铜片仍在掌心；不可知之地会记录他的血。
7. **苏清寒状态**：外部封锁尚在，她知道楚妄还活着并准备守出口。
8. **霜华线**：她已公开违逆过一次，但仍未真正离开苏清寒。

### 待解决的问题
1. 霜华如何在不轻飘飘背叛的前提下离开苏清寒？
2. 她要带走什么证据或记忆，才能证明自己是忠于苏清寒真正本心？
3. 赤焰如何把救命旧债和对夜红莲的忠义分开？
4. 顾青鸾的错字证据能否送进不可知之地，还是只能留在外部联盟手里？
5. 楚妄如何在因果账失灵时判断不可知之地的风险？

### 第46章写作抓手
- 从太上封锁阵和苏清寒接住焦黑雪符承接，霜华看见苏清寒仍要守出口。
- 霜华离开不是背叛小姐，而是认定“真正的苏清寒”不会任天道继续利用她。
- 她可以带走一枚残雪符、前世记忆碎片或被顾青鸾证据触动的旧记录，去找能帮楚妄的人。
- 苏清寒不能被写成已经醒悟，她仍偏执、痛苦、强势。

### 下一步拷问方向
1. 霜华离开时，苏清寒会阻拦还是默许一瞬？
2. 霜华最能证明苏清寒本心的记忆是哪一段？
3. 不可知之地茶棚石碑上的“待观”会不会开始改写四人的位置？
4. 夜红莲送出的三句话会以什么方式到达楚妄手里？
