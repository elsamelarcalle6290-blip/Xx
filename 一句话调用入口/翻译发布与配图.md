# 翻译发布与配图

## 功能
把翻译、公众号排版、公众号发布、微博发布、X 发布、小红书图卡、封面图、文章配图这些动作统一成中文请求入口。

## 使用方式
你可以直接说：
- 把这篇文章翻译成英文
- 把这篇 markdown 转成公众号
- 把这篇文章发公众号
- 把这段内容发微博
- 把这篇内容发到 X
- 给这篇文章做小红书图卡
- 给这篇文章做封面图
- 给这篇文章配几张图

默认调用方向：
- 翻译 -> `baoyu-translate`
- 公众号排版 -> `baoyu-markdown-to-html`
- 发公众号 -> `baoyu-post-to-wechat`
- 发微博 -> `baoyu-post-to-weibo`
- 发 X -> `baoyu-post-to-x`
- 小红书图卡 -> `baoyu-xhs-images`
- 封面图 -> `baoyu-cover-image`
- 文章配图 -> `baoyu-article-illustrator` 或 `baoyu-image-gen`
