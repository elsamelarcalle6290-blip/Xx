# 短视频文案调用说明

这份文档用于说明以后如何自动调用 `短视频文案改写提示词.md`。

## 默认调用方式

当用户说出以下任意表达时，默认调用 `短视频文案改写提示词.md`：

- 口播文案
- 口播内容
- 文案内容
- 文案
- 短视频文案
- 短视频口播
- 帮我改一下这段文案
- 帮我优化这段口播
- 把这段话改成短视频文案
- 直接粘贴一段明显像短视频口播或视频解说的文字

## 执行规则

1. 如果用户明确给出平台、受众、风格、时长、字数、语气，以用户要求为准。
2. 如果用户只给出文案，没有额外说明，默认按“短视频口播微调润色”处理。
3. 改写时要保留原文核心意思，不改变主题，不凭空增加未经用户提供的事实。
4. 默认以微调为主，不大改结构，不大换表达，不把原文改成另一篇文案。
5. 优先提升口语流畅度、句子顺口度、停顿节奏和自然表达。
6. 输出时直接给可用成稿，不暴露“我正在套用提示词”这类过程说明。

## 默认输出方向

默认把文案轻微调整成更适合真人口播的版本：

1. 原文核心意思不变。
2. 原文叙述顺序尽量不变。
3. 原文表达习惯尽量保留。
4. 句子更短、更顺口。
5. 信息表达更清楚。
6. 节奏更适合短视频口播。
7. 只在必要时微调开头和结尾。

## 改写幅度控制

默认改写幅度控制在原文的三成以内。

可以改：

1. 拗口句。
2. 重复句。
3. 生硬句。
4. 停顿不自然的句子。
5. 明显不适合口播的书面表达。

不要改：

1. 不要重排整篇结构。
2. 不要替换掉原文主要观点。
3. 不要新增原文没有的事实和案例。
4. 不要强行制造冲突、悬念、反转。
5. 不要把短视频文案改成公众号文章或长文评论。

只有当用户明确说“重写”“大改”“爆款改写”“重新写一版”时，才可以放大改写幅度。

## 需要反问的情况

只有在以下情况才需要先问用户：

1. 原文缺失，完全没有可改写内容。
2. 用户要求的平台、风格、禁区互相冲突。
3. 文案涉及医疗、法律、金融投资、隐私、未成年人等高风险内容，且素材不足以支撑准确表达。

除此之外，不需要用户额外说“调用短视频提示词”，直接按短视频文案改写流程执行。
