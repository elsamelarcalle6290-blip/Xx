# 扩展指南

> 本文档面向skill维护者，执行去AI味时无需加载。

---

## 如何添加新题材适配

1. 确定题材特征：对话风格、节奏、情绪、禁用、特有元素
2. 创建专用替换表：至少3对AI写法→人类写法
3. 标注可保留元素：该题材特有的表达方式
4. 参考现有格式：复制 genre-styles.md 中的模板
5. 测试验证：用实际文本测试适配效果

## 如何添加新规则

1. 确定规则类型：视角/语言/人物/情节/绝对禁止
2. 编写规则描述：简洁、明确、可执行
3. 分配规则编号：延续现有编号（56、57...）
4. 添加正误示例：至少1对对比
5. 更新相关章节：检查是否需要更新冲突裁决表

## 如何创建自定义白名单

某些词在你的特定题材中是合理的，但skill建议禁用。

**操作步骤**：
1. 在文档顶部创建白名单注释
2. 执行skill时，跳过白名单中的词
3. 定期回顾白名单，确保不会过度放宽

**注意事项**：
- 白名单尽量短（不超过10个词）
- 每个词标注使用场景
- 定期检测白名单词是否导致AI味回升
