## 核心哲学

**原则1：不是改错，是改味。** AI味是风格问题——过于书面化、对仗工整、面面俱到。去AI味是把文字从"完美"拉回"真实"。

**原则2：改最少，效果最大。** 能改一个词就不改一句，能删一句就不重写一段。

**原则3：保留作者意图。** 只改"怎么说"，不改"说什么"。

**核心认知：AI味的根在结构，不在措辞。** 措辞改一百遍，叙事骨架是AI的，读起来还是AI。

## 第二部分：46条禁止规则【标准模式】

### 一、视角与叙事（1-2）

1. 杜绝视角隐性越界：不泄露聚焦角色感知不到的信息
2. 禁止随意切换视角：单一场景视角固定，跨场景需过渡

### 二、语言与句式（3-14）

3. 杜绝AI口癖：禁用"只见、就在这时、片刻后、随即、于是、因此、不由得、不禁、似乎、仿佛、好像"
4. 杜绝重复句式模板：规避"他XX地说道，XX地看着，XX地走过去"
5. 杜绝无效副词泛滥：删除"非常、极其、格外、稍稍、默默"
6. 杜绝语句冗余啰嗦：不反复表述同一意思
7. 禁止小标题、序号、加粗标题、项目符号
8. 杜绝段落长短极端化
9. 禁止连续三句以上结构相同的句式
10. 杜绝句式结构单一
11. 杜绝形容词堆砌、用词重复
12. 杜绝比喻生硬违和
13. 杜绝用词同质化
14. 杜绝否定对比与弱转折排比：禁止【没有A，没有B】【不是A，而是B】【虽然A，但是B】

### 三、人物描写（15-27）

15. 杜绝人物外貌模板化
16. 杜绝外貌与人设脱节
17. 禁止无配套描写的纯台词对话
18. 杜绝对话台词同质化
19. 杜绝对话无意义水字数
20. 杜绝对话语气与心理割裂
21. 杜绝多人对话指代混乱
22. 严禁拆分一句一动作：禁止重复主语"他/她"
23. 杜绝动作违反生理逻辑
24. 杜绝动作与场景脱节
25. 杜绝人设OOC、行为跳跃
26. 杜绝人物动机模糊悬空
27. 杜绝心理活动直白空洞

### 四、情节与结构（28-46）

28. 杜绝人物成长/转变突兀
29. 杜绝环境描写悬浮架空
30. 杜绝环境描写千篇一律
31. 杜绝感官描写单一（不只依赖视觉）
32. 杜绝场景转换无过渡
33. 杜绝开篇废话铺垫
34. 杜绝悬念悬空烂尾
35. 杜绝情节逻辑漏洞
36. 杜绝冲突强行生硬
37. 杜绝情节套路化模板化
38. 杜绝剧情水字数
39. 杜绝节奏全程平扁
40. 杜绝倒叙/插叙混乱
41. 杜绝章节内容断层
42. 杜绝扩写/续写OOC
43. 禁止强行说教、直白点题、刻意升华
44. 杜绝主题强行升华
45. 杜绝细节前后矛盾
46. 禁止排比式否定、排比式强调、排比式抒情

### 五、总则（47-48）

47. **以上46条的核心总则**：禁止一句一动作、连续主语"他/她"、机械流水账；禁止纯台词对话、上帝视角、AI口癖；禁止脸谱化人物、同质化台词、模板化情节、空洞化心理；禁止副词泛滥、无效修辞、细节矛盾、逻辑bug
48. **结尾总则**：禁止散文式收尾——结尾仅用一个具体的小动作或感官描写自然结束，禁止抒情总结、哲理金句、伏笔式预告

## 第三部分：三大高危结构【新手必过】

### 高危一：时间线平推
```
先A → 再B → 再C → 再D
```
典型词：「然后」「接着」「之后」「于是」

**解法**：跳接+留白。只写关键画面，中间过渡全砍。

| AI写法 | 人类写法 |
|--------|----------|
| 他把干粮码好。然后拿着净水器去河边。装好滤芯接了水。喝了一口。 | 干粮码好了。净水器试过，水是干净的。 |

### 高危二：列举结构
```
第一个……第二个……第三个……
```

**解法**：用物理特征代替编号，最重要的放最后。

| AI写法 | 人类写法 |
|--------|----------|
| 第一个打开，是一套厨具。第二个箱子，空气净化器。第三个箱子最沉，是压缩干粮。 | 一套厨具。翻了翻，又开了一个，空气净化器。最沉的那个箱子晃着响，划开一看，干粮。 |

### 高危三：问答式对话
```
A问→B答→A再问→B再答
```

**解法**：信息倒灌，中间插动作或反应。

| AI写法 | 人类写法 |
|--------|----------|
| 「这是什么。」「量子封印锁。」「什么意思。」「强制开启会销毁。」 | 「我碰了会怎么样。」「热敏反应膜，检测到非授权操作，零点三秒升温到八百度，里面的东西全毁。」 |

## 第五部分：优先级冲突处理【专家模式】

| 冲突场景 | 裁决 | 理由 |
|----------|------|------|
| 节奏短句 vs 信息密度长句 | **信息密度优先** | 信息不能丢，节奏可通过段落控制 |
| 禁用词 vs 人物口语习惯 | **人物习惯优先** | 标志性用语是人物塑造的一部分 |
| 去AI味 vs 保留原意 | **保留原意优先** | 宁可保留AI味，不扭曲作者意图 |
| 流畅度 vs 检测通过率 | **流畅度优先** | 通过但别扭 = 失败 |
| 风格适配 vs 通用规则 | **风格适配优先** | 古风的"乃"比"是"更自然 |

**硬约束（不可妥协）**：二分对照壳、AI身份口吻、剧情逻辑bug、人设OOC

**软约束（可酌情）**：冒号数量、极值判断、段落长度

## 第六部分：人类写作核心机制

**叙事引力**：每段必须指向一个未完成状态——未确认的信息、未解决的冲突、即将发生的变化。

**不均匀原则**：禁止均匀节奏、均匀信息密度、均匀段落长度、均匀情绪推进。稳定可以极短，混乱可以极长。

**信息密度呼吸**：高密度（动作/事件）→ 低密度（环境/感知）→ 空白段（停顿）→ 循环。

**注意力漂移**：所有偏移必须来自感官变化、身体行为、环境变化、外部事件或记忆闪回。禁止无原因跳转。

## 第七部分：替换参考【新手必过】

### 禁用词替换

| 类别 | 禁用词 | 替换为 |
|------|--------|--------|
| 情态 | 仿佛、好像、犹如、宛若、一丝、一抹、些许、几分、隐约 | 删或具体描写 |
| 动作 | 深吸一口气、缓缓、不禁、微微、轻轻、淡淡 | 具体动作或删 |
| 表情 | 眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩 | 动作替代 |
| 心理 | 心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得 | 用行为展示 |
| 判断 | 不容置疑、不易察觉、显而易见、毫无疑问、不可否认 | 直接说事实 |
| 过渡 | 突然、瞬间、不由自主、情不自禁、自然而然 | 删或具体化 |

**禁用句式**："他终于明白…""他这才意识到…""此刻，他…""一切…都…""这一刻…""他知道…"

### 情绪外化（Show Don't Tell）

| 情绪 | ❌ Tell | ✅ Show |
|------|---------|---------|
| 紧张 | 他感到紧张 | 他攥紧了手里的纸杯，水洒出来一些 |
| 愤怒 | 愤怒在心中燃烧 | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 悲伤 | 一丝悲伤涌上心头 | 她低头搅着咖啡，搅了很久 |
| 害怕 | 恐惧笼罩了他 | 他的背贴在墙上，不敢动 |
| 失望 | 她感到失落 | "哦。"她把手机锁了屏 |
| 惊讶 | 瞳孔微微收缩 | 他张了张嘴，什么都没说出来 |
| 尴尬 | 他感到尴尬 | 他摸了摸鼻子，视线飘向窗外 |
| 嫉妒 | 她心中涌起嫉妒 | 她把手机翻了个面，扣在桌上 |
| 疲惫 | 他感到非常疲惫 | 他靠在墙上，慢慢滑坐下去 |
| 兴奋 | 他感到无比兴奋 | 他把拳头在空中挥了一下 |

## 第八部分：执行流程

### 完整流程

```
输入文本 → 选模式 → 识别题材 → 结构处理(高危3) → 红线扫描(11条) →
规则扫描(46条) → 题材适配 → 替换参考 → 节奏打碎 → 三遍法 → 收尾检查 → 输出
```

### 五步操作

**第一步：结构层**（决定性，必须优先）
1. 砍时间线过渡词（「然后」「接着」「之后」「于是」）
2. 打散列举顺序
3. 改问答式对话为信息倒灌

判断标准：删掉中间3-5段，读者还能跟上，说明那些是注水。

**第二步：红线扫描** — 11条逐项检查，命中即改

**第三步：规则扫描** — 46条逐项检查，命中即改

**第四步：节奏打碎与替换**
- 每段最多2-3句
- 句长匹配场景：打斗3-8字、对话口语化、日常8-15字、描写不超过20字
- 情绪外化：用行为代替形容词

**第五步：结尾处理**
- ❌ 禁止：总结感悟、升华感叹、哲理收尾、伏笔预告
- ✅ 正确：动作收尾、对话收尾、悬念收尾、感官描写自然结束

| ❌ AI写法 | ✅ 人类写法 |
|----------|------------|
| 他站在窗前，终于明白了生活的真谛——放手才是最好的选择。 | 他把烟掐了，回屋睡觉。 |
| 这一刻，一切都变了。她知道，从今以后，人生将翻开崭新的一页。 | 她关上了那扇门。没回头。 |

## 第九部分：三遍法

### Pass 1：去泛化（去掉80%AI味）
- 抽象情绪句 → 删或具体动作
- 假深度句 → 删
- 工整对比句式 → 打散
- 装饰性形容词 → 白描
- 过度"于是""然而""此刻" → 删一半

### Pass 2：去书面化
- 分析性用词（"机制""结构""逻辑""体系"）→ 日常表达
- 抽象名词滥用 → 直接说事
- 体制内用语（"进一步""深入""推进"）→ 删

### Pass 3：回人味
- 具体感官细节（气味、温度、触感）
- 角色说话方式区分
- 长短句交错
- 场景特有记忆点
- 角色口头禅

原则：少即是多，每段加1-2个具体细节。

## 第十部分：量化指标

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度 | <=5处/千字 | 6-15处/千字 | >15处/千字 |
| 连续排比段落 | <=2段 | 3-4段 | >=5段 |
| 平均段落句数 | <=3句 | 3-5句 | >5句 |
| 对话标签密度 | <=30% | 30-50% | >50% |

取最高档位。轻度→Pass1+红线；中度→Pass1+2+红线+重写；重度→完整三遍+重写。

## 第十一部分：网文技法

- **钩子密度**：每1000字至少2个悬念钩子
- **爽点节奏**：「打脸」「反转」「升级」要有具体数据支撑
- **代入感**：主角行为能被读者理解、共鸣
- **信息差**：操控读者已知信息，制造情绪波动

**对话优化**：冲突→加语气词（"嗯""哦""行吧"）；解释性→删掉；紧张→用动作穿插

**主语锚定**：新场景开头用名字 → 连续动作省略主语 → 切换时用他/她 → 关键转折用名字

**人物人味检查**：出声了吗？露情绪了吗？有停顿吗？有身体反应吗？

## 第十二部分：常见错误诊断

| 症状 | 原因 | 方案 |
|------|------|------|
| 改完读起来别扭 | 过度删除 | 回滚部分修改，保留原意优先 |
| 检测通过率没提升 | 只改措辞没改结构 | 重点处理三大高危结构 |
| 人物不像人了 | 标志性用语被误删 | 检查人物习惯用语 |
| 节奏太平 | 段落长度太均匀 | 故意制造长短交替 |
| 对话像说明书 | 问答式对话未处理 | 信息倒灌，插动作 |
| 结尾还是AI味 | 散文式收尾未处理 | 动作/对话/悬念收尾 |
| 改完字数太少 | 过度删除 | 用具体细节替代，非直接删除 |

## 第十三部分：语气词专项处理表【专家模式】

> 语气词是判断AI味的重要指标真人写作会大量使用语气词，AI写作几乎不用。

### 语气词分类与处理

| 类别 | AI风格（禁用） | 真人风格（保留） | 处理方式 |
|------|---------------|-----------------|----------|
| **肯定词** | "确实""的确""的确如此" | "嗯""对""是""行" | 删除AI肯定词，保留口语肯定 |
| **否定词** | "并非如此""绝非如此" | "不""没""别""不是" | 删除AI否定词，保留口语否定 |
| **确认词** | "毋庸置疑""不言而喻" | "真的""确实"（口语） | 删除AI确认词 |
| **感叹词** | "令人惊叹""实属罕见" | "哇""靠""天哪""我去" | 删除AI感叹词，保留口语感叹 |
| **过渡词** | "综上所述""总而言之" | "然后""接着""对了" | 删除AI过渡词 |
| **引用词** | "有道是""古人云""常言道" | "他说""她说" | 删除AI引用词 |

### 语气词替换表

| ❌ AI语气词 | ✅ 人类语气词 |
|-----------|--------------|
| 确实如此/的确如此/确实如此 | 嗯/是/对 |
| 并非如此/绝非如此 | 不/没/不是 |
| 不言而喻/毋庸置疑 | 真的/确实 |
| 令人惊叹/实属罕见 | 哇/靠/我去 |
| 综上所述/总而言之 | 然后/对了/哎 |
| 有道是/古人云 | 他说/她说 |
| 众所周知/不可否认 | 大家/其实 |

### 语气词密度检测

正常人类写作语气词密度：每100字2-5个

**检测方法**：统计语气词出现次数，低于阈值则需要增加口语化表达。


### 风格问题诊断
