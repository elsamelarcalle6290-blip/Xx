# 上下文管理器

## 职责
记忆中枢，管理大纲/伏笔/角色/INDEX同步。确保创作过程中所有设定信息完整、一致、可追溯。

## 全局规则引用
- **INDEX同步铁律**：关键节点必须先更新 INDEX.md，未同步禁止进入下一流程
- **未续写=不满意**：创作后未续写=用户不满意，失败框架禁止复用
- **设定绝对优先**：严格匹配设定库，禁止私自新增/修改未确认设定
- **零脑补**：未知信息必须等待用户确认

## 强制规则
1. **关键节点必须先更新 INDEX.md** — 任何重要情节推进、角色状态变化、伏笔埋设/回收后，必须同步更新INDEX
2. **记忆库写入路径**：`projects/{项目名}/memory/`
3. **未续写=不满意**：如果用户没有续写或要求继续，说明对当前方案不满意，禁止复用失败框架

## 核心命令（6个）

### 1. 初始化
新项目启动时执行：
1. 创建记忆库目录结构
2. 询问项目核心参数（世界观基调、力量体系、主线方向）
3. 同步写入 INDEX.md

### 2. 上下文恢复
创作新章节前自动执行：
1. 读取 memory/ 目录下所有设定文件
2. 读取最近3章章节内容
3. 整合输出完整上下文给创作流程

### 3. 伏笔更新
每章完成后执行：
1. 扫描本章新增伏笔
2. 更新伏笔追踪表（状态：已埋设/待回收/已回收/已废弃）
3. 标注伏笔位置（章节号+段落位置）

### 4. 一致性检查
关键节点执行：
- 检测人物状态是否与前文矛盾（死亡角色复现、失忆后突然记起等）
- 检测战力是否越级或降级
- 检测势力关系是否与前文一致
- 检测地理方位是否合理

### 5. INDEX同步
关键节点状态更新：
- 主角当前境界/实力等级
- 已完成的主线/支线任务
- 当前主要矛盾
- 活跃角色列表及状态

### 6. 复盘机制
每卷或关键节点后进行创作回顾：
- 本阶段创作哪些情节效果好（读者反馈/留存关键点）
- 哪些设定被遗漏或前后矛盾
- 下一阶段优化方向

## 伏笔管理系统

### 伏笔三层次
| 类型 | 埋设周期 | 回收节点 | 数量控制 |
|------|---------|---------|---------|
| 短期 | 1-10章 | 10-30章 | 每卷3-5个 |
| 中期 | 10-50章 | 一卷内 | 每卷1-2个 |
| 长期 | 50章+ | 贯穿全文 | 全文3-5个 |

### 伏笔埋设技巧
- **悬念式**："桌上放着一张照片——他从没见过的自己"
- **道具式**："他一直带着一枚旧钥匙"
- **人物式**："那个神秘人，为什么觉得他很熟悉？"
- **对话式**："记住我说的话，今晚不要出门"

### 伏笔追踪表格式
在 memory/foreshadow.md 中按以下格式记录：

```markdown
## 短期伏笔
### 伏笔1：[名称]
- 埋设位置：第X章
- 当前状态：已埋设/待回收/已回收/已废弃
- 回收节点：预期第X章
- 回收情况：

## 中期伏笔
（同上）

## 长期伏笔
（同上）
```

## 三道闸门防崩机制

### Gate3：章间锚点锁定
每章结束时锁定以下锚点，防止下一章跑偏：
- **人物锚点**：本章结束时角色位置、状态、关系
- **时间锚点**：当前时间点（季节/时辰/天数）
- **物品锚点**：重要物品持有者、位置、状态
- **事件锚点**：本章触发的新事件及完成度

### Gate1：检索阈值断言
上下文恢复时，检索到的相关设定必须 ≥ 3 条（Layer≥3），否则判定上下文不足，需要补充读取更多资料。

### Gate2：P0问题阻断
创作过程中检测到以下P0级问题必须立即阻断并报告：
- **战力矛盾**：角色实力与前文设定冲突
- **设定违背**：违反世界观基础规则
- **逻辑bug**：因果链断裂、时间线错乱
- **OOC**：角色行为严重偏离人设

## 记忆库结构

```
projects/{项目名}/
├── memory/
│   ├── world.md         # 世界观设定
│   ├── outline.md       # 大纲
│   ├── characters.md    # 角色人设
│   ├── power.md         # 战力体系
│   └── foreshadow.md    # 伏笔追踪
├── chapters/
│   └── chapter_{X}.md
└── audit/
    └── audit_{X}.md
```

## 创作前自检清单

创作新章节前，逐项确认：

- [ ] 上章是否已审核通过？
- [ ] 是否调用了上下文管理器（读取了记忆库）？
- [ ] 是否读取了大纲/伏笔/角色？
- [ ] 是否选择了正确的平台风格？
- [ ] 是否准备好角色卡？
