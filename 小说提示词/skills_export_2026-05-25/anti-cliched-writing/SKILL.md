# 反套路写作规范

## 核心原则

写作必须真实自然，禁止一切故弄玄虚、强行解释、刻意渲染的写法。

---

## 一、禁止句式清单

### 1.1 禁止的对比否定句式

**完全禁止以下句式结构：**

```
❌ "不是什么，是什么"
❌ "不是什么，而是什么"
❌ "不像是A，像是B"
❌ "不是A，是B"
```

**错误示例：**
```
❌ "那不是恐惧，是某种更深层的东西。"
❌ "这不是普通的迷雾，而是深渊的投影。"
❌ "不像是血，像是蜡。"
❌ "不是耳朵听到的，是直接出现在脑子里。"
```

**正确替代：**
```
✅ 直接陈述事实：
"他感到恐惧。"
"迷雾中有轮廓。"
"液体是蜡。"
"声音出现在脑子里。"

✅ 用具体描述替代：
"液体有蜂蜡的味道。"
"迷雾里有建筑轮廓。"
"他脑子里出现了声音。"
```

---

### 1.2 禁止的认知矛盾句式

**完全禁止以下句式：**

```
❌ "我不知道，但我知道……"
❌ "我不确定，但我确定……"
❌ "我无法解释，但我明白……"
❌ "说不清楚，但我知道……"
```

**错误示例：**
```
❌ "我不知道那是什么，但我知道它在看我。"
❌ "我不确定听到了什么，但我确定有人说话。"
❌ "说不清楚，但我知道不对劲。"
```

**正确替代：**
```
✅ 分开陈述或删除后半句：
"那东西在看我。"（直接陈述）
"有人说话。"（删除"我不知道"）
"情况不对。"（删除"说不清楚"）

✅ 用事实替代：
"他感觉到注视。"
"声音从某个方向传来。"
"数据出现异常。"
```

---

### 1.3 禁止的反应描写句式

**完全禁止以下句式：**

```
❌ "愣了一下"
❌ "愣住"
❌ "愣了几秒"
❌ "怔住"
❌ "怔了一下"
```

**错误示例：**
```
❌ "他愣了一下，然后说……"
❌ "她愣住了，看着那个东西。"
❌ "他怔了几秒，才反应过来。"
```

**正确替代：**
```
✅ 用具体动作替代：
"他停下脚步。"
"她看着那个东西，没说话。"
"他看了三秒，然后转身。"

✅ 用生理反应替代：
"他的手停在半空。"
"她的呼吸停了一拍。"
"他眨了两次眼。"

✅ 直接删除：
"他说……"（删除"愣了一下"）
"她看着那个东西。"（删除"愣住"）
```

## 二、禁止故弄玄虚写法

### 2.1 禁止"别人听不见/看不见"套路

**完全禁止以下写法：**

```
❌ "他听到了什么，别人听不到。"
❌ "只有他能听见那个声音。"
❌ "她看见了别人看不见的东西。"
❌ "只有她能看到那个影子。"
❌ "其他人什么都没听到，但他听到了。"
```

**错误示例：**
```
❌ "陆明轩什么都没听到，但沈砚临听到了低语。"
❌ "只有沈砚临能听到那个声音。"
❌ "别人看不见，但他看见了深渊。"
```

**正确替代：**
```
✅ 客观陈述事实：
"日记记载船员报告听到声音。"
"沈砚临检查设备，发现异常信号。"
"数据显示声波频率超出正常范围。"

✅ 用科学依据解释：
"理智值低于85的人会感知到异常信号。"
"检测仪显示声波存在。"
"设备记录到声音频率。"

✅ 用群体现象替代：
"多个船员报告听到声音。"
"乘客集体出现相同症状。"
"日记记录了群体性感知异常。"
```

---

### 2.2 禁止刻意渲染恐怖

**完全禁止以下写法：**

```
❌ "脊背发凉"
❌ "毛骨悚然"
❌ "浑身发冷"
❌ "冷汗直流"
❌ "心脏骤停"
❌ "呼吸停滞"
❌ "血液凝固"
❌ "头皮发麻"
❌ “同一场景重复出现”
```

**错误示例：**
```
❌ "他感到脊背发凉，毛骨悚然。"
❌ "看到那个东西，他浑身发冷。"
❌ "他的心脏骤停了一瞬。"
```

**正确替代：**
```
✅ 用具体生理反应：
"他出汗了。"
"他的呼吸频率变慢。"
"他的心率从72降到65。"

✅ 用环境描写替代：
"房间温度下降了五度。"
"空气湿度增加了。"
"光线变暗了。"

✅ 用动作描写替代：
"他后退了一步。"
"他握紧了手里的东西。"
"他加快脚步。"
```

---

### 2.3 禁止模糊恐怖描写

**完全禁止以下写法：**

```
❌ "某种说不出的恐惧"
❌ "某种无法描述的东西"
❌ "某种深层的东西"
❌ "某种存在"
❌ "有什么东西在……"
❌ "仿佛有什么……"
```

**错误示例：**
```
❌ "他感到某种说不出的恐惧。"
❌ "迷雾里有某种存在。"
❌ "仿佛有什么东西在看着他。"
❌ "某种无法描述的东西出现在镜子里。"
```

**正确替代：**
```
✅ 直接描述具体内容：
"他感到恐惧。"（删除"某种说不出的"）
"迷雾里有轮廓，尺寸超过船体。"（具体化）
"有人看着他。"（删除"仿佛有什么东西"）
"镜子里出现灰色空间，有雾气和建筑轮廓。"（具体描述）

✅ 用数据替代模糊词：
"轮廓尺寸超过船体长度。"
"温度下降了十度。"
"理智值降低了15点。"
```

## 三、禁止强行解释

### 3.1 禁止反转式解释

**完全禁止以下写法：**

```
❌ "表面是A，实际是B"
❌ "看起来是A，其实是B"
❌ "以为是A，结果是B"
❌ "看似A，实则B"
```

**错误示例：**
```
❌ "表面是蜡像，实际是深渊的记录。"
❌ "看起来是血，其实是蜡。"
❌ "以为是迷雾，结果是深渊投影。"
❌ "看似普通案件，实则深渊教会的阴谋。"
```

**正确替代：**
```
✅ 直接陈述事实：
"蜡像保持微笑表情。"（删除"表面是"）
"液体成分检测为蜂蜡。"（删除"看起来是"）
"迷雾中有轮廓。"（删除"以为是"）
"案件关联深渊教会标记。"（删除"看似"）

✅ 用证据推导：
"显微镜显示物质结构为蜡质。"
"化学分析确认成分。"
"符号对应深渊教会档案记录。"
```

---

### 3.2 禁止哲学式强行升华

**完全禁止以下写法：**

```
❌ "献给那些凝视深渊的人"
❌ "深渊也在凝视你"
❌ "真相永远……"
❌ "命运的齿轮开始转动"
❌ "某种更深层的东西"
❌ "触及了本质"
```

**错误示例：**
```
❌ "献给那些凝视深渊的人。"（作为解释性句子）
❌ "他触及了某种更深层的东西。"
❌ "命运的齿轮开始转动。"
❌ "真相永远埋藏在迷雾中。"
```

**正确替代：**
```
✅ 仅作为引用或他人说的话：
"望远镜上刻着一行字：献给那些凝视深渊的人。"（作为刻字内容）
"日记最后一页写着这句话。"（作为记录内容）

✅ 删除升华句：
"他发现了线索。"（删除"触及了本质"）
"事件开始发展。"（删除"命运的齿轮"）
"真相需要进一步调查。"（删除"永远埋藏"）
```

## 四、正确写作原则

### 4.1 真实性原则

**核心：只写能被观察、测量、记录的事实**

```
✅ 可观察的：动作、表情、环境变化
✅ 可测量的：温度、时间、距离、数据
✅ 可记录的：对话内容、日记、档案、照片

❌ 不可观察的："某种感觉""某种存在""无法描述的东西"
```

---

### 4.2 具体性原则

**核心：用具体替代抽象，用数据替代模糊**

```
✅ 具体动作："他后退了一步"替代"他感到恐惧"
✅ 具体数据："温度下降十度"替代"空气变冷"
✅ 具体描述："灰色空间，有雾气和轮廓"替代"某种东西"

❌ 抽象词：某种、仿佛、似乎、好像、某种深层
```

---

### 4.3 逻辑性原则

**核心：所有结论必须有依据**

```
✅ 有依据："日记记录船员听到声音"替代"只有他能听到"
✅ 有证据："成分检测为蜂蜡"替代"不像是血"
✅ 有来源："档案记载深渊教会标记"替代"这是深渊教会"

❌ 无依据：强行解释、强行升华、无证据的结论
```

---

### 4.4 克制性原则

**核心：情感表达要克制，用细节替代情绪词**

```
✅ 用动作："手指停在照片边缘"替代"震惊"
✅ 用生理反应："手发抖"替代"害怕"
✅ 用延迟反应："看了很久，然后转身离开"替代"悲伤"

❌ 情绪词：震惊、恐惧、悲伤、愤怒、绝望（直接写出）
❌ 强化词：深深、某种、无法、永远
```

## 五、实战对照表

### 5.1 句式对照

| 禁止句式 | 正确替代 |
|---------|---------|
| 不是A，是B | 直接说B |
| 不是A，而是B | 直接说B |
| 我不知道，但我知道 | 删除前半句，只说后半句 |
| 愣了一下 | 删除或用具体动作替代 |
| 只有他能听到 | 多人报告听到/设备记录到 |
| 看见别人看不见的 | 设备观测到/群体观察到 |
| 某种说不出的恐惧 | 他感到恐惧（删除修饰） |
| 某种存在 | 具体描述是什么 |
| 表面是A，实际是B | 直接说B（删除"表面是"） |

---

### 5.2 场景对照

**恐怖场景：**

```
❌ 错误写法：
他感到脊背发凉，某种说不出的恐惧涌上来。只有他能听到那个声音，别人什么都听不到。那不是普通的迷雾，而是深渊的投影。他愣住了，看着那个东西。

✅ 正确写法：
房间温度下降十度。日记记载船员报告听到声音，频率超出正常范围。迷雾中有轮廓，尺寸超过船体长度。他停下脚步，观察了三秒。
```

**情感场景：**

```
❌ 错误写法：
他感到深深的悲伤，某种无法描述的痛苦在心里翻涌。他愣了一下，然后说："妈……"

✅ 正确写法：
他看着照片，手指停在边缘。看了很久，然后说："妈……"
```

**悬疑场景：**

```
❌ 错误写法：
这不是普通的案件，而是深渊教会的阴谋。表面是蜡像，实际是深渊的记录。他不知道那是什么，但知道它在看着他。

✅ 正确写法：
案件关联深渊教会标记。蜡像保持微笑表情，成分检测为蜡质。他感觉到注视，转过头观察四周。
```

## 六、检查清单

### 写作后必查项：

```
□ 是否出现"不是A，是B"句式？
□ 是否出现"我不知道，但我知道"句式？
□ 是否出现"愣了一下"？
□ 是否出现"只有他能听到/看见"？
□ 是否出现"脊背发凉""毛骨悚然"等恐怖词？
□ 是否出现"某种""无法描述"等模糊词？
□ 是否出现"表面是A，实际是B"强行解释？
□ 是否出现哲学式升华句？
□ 所有结论是否有依据？
□ 所有描述是否具体？
□ 情感表达是否克制？
```

本规范适用于：
- 所有小说写作场景
- 所有章节创作
- 所有情感描写
- 所有悬疑描写
- 所有恐怖描写
- 所有推理过程

**强制执行：**
每次写作前必须查阅本规范
每次写作后必须对照检查清单

## 八、核心理念

**写作的最高原则：真实、具体、逻辑、克制**

- 真实：只写可观察、可测量、可记录的事实
- 具体：用具体替代抽象，用数据替代模糊
- 逻辑：所有结论必须有依据
- 克制：情感表达要克制，用细节替代情绪词

**禁止一切套路化、故弄玄虚、强行解释的写法。**
