# 设定合同与防吃书

## 用途

用于长期连载时防止前后矛盾。每次写正文、改正文、补大纲前，都先检查硬设定。

## 硬设定分级

### S 级：不可改

- 小说书名、主角姓名、核心金手指、重生原因、主要职业路线。
- 游戏名 / 世界规则名。
- 唯一性设定，如唯一隐藏职业、唯一神器、唯一传承。
- 充值入口是否关闭、是否能补开、积分是否能交易。
- 主角前世知道什么、不知道什么。

### A 级：可补充，不可推翻

- 职业、技能、装备、货币、门派、排行榜、社交规则。
- 主角战力限制和成长阶段。
- 阵营关系、主城规则、死亡复活规则。
- 重要配角的身份、利益、已发生行为。

### B 级：可优化

- 章节标题、桥段顺序、台词、论坛帖子、路人反应。
- 奖励名称的美化。
- 小支线和小人物。

## 防吃书检查

写前检查：

1. 本章新增设定是否和 S 级设定冲突？
2. 主角是否知道了前世不该知道的信息？
3. 角色是否突然改变立场但没有事件支撑？
4. 装备、技能、等级是否超出已定限制？
5. 上一章结尾钩子是否被承接？
6. 本章新增伏笔是否记录？

## 修改设定流程

如果必须改设定，先输出“设定修订提案”：

- 原设定
- 新设定
- 修改原因
- 影响章节
- 需要同步修改的文件
- 是否会造成吃书

未经用户确认，不直接改 S 级设定。
