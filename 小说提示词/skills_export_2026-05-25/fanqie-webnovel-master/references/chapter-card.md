# 章纲与章节任务卡

## 每章任务卡字段

- 章节名：
- 章节定位：推进主线 / 爽点爆发 / 过渡蓄力 / 反派登场 / 世界规则揭示
- 主视角：
- 承接上章：
- 本章主事件：
- 本章冲突：
- 本章爽点：
- 本章新增设定：
- 本章人物变化：
- 本章伏笔：
- 结尾钩子：
- 禁写内容：

## 章纲标准

好章纲不是“主角继续升级”，而是有明确事件：

- 谁想要什么？
- 谁阻止他？
- 主角做了什么选择？
- 这个选择造成了什么后果？
- 下章为什么必须接着看？

## 章节节奏

常用节奏：

1. 开头承接上章钩子。
2. 迅速给出本章问题。
3. 中段推进冲突，不要只解释设定。
4. 后段兑现一个爽点或反转。
5. 结尾抛出新危险、新奖励、新人物或新误判。

## 钩子类型

- 奖励钩子：新奖励出现但未领取。
- 危机钩子：危险逼近但未爆发。
- 人物钩子：某人认出主角或开始调查。
- 规则钩子：系统提示出现异常。
- 舆论钩子：论坛 / 直播 / 排行榜引爆。
