# 技能创建助手

帮助用户创建新的技能(Skill)，让AI能够更好地完成特定任务。

## 什么是技能(Skill)？

技能是一组指导AI完成特定任务的指令集合。通过创建技能，你可以让AI：
- 遵循特定的工作流程
- 使用特定的输出格式
- 记住重要的规则和约束
- 自动化重复性任务

## 创建技能的流程

### Step 1: 了解用户需求

首先询问用户以下问题：
1. 这个技能要帮助AI完成什么任务？
2. 什么情况下应该触发这个技能？（用户可能会说什么话）
3. 期望的输出格式是什么？
4. 有没有特殊的规则或约束？

### Step 2: 编写技能文件

技能文件(SKILL.md)的基本结构：

```markdown
---
name: 技能名称
description: 技能描述，说明何时使用这个技能
---

# 技能标题

[技能的详细说明]

## 工作流程

### Step 1: [步骤名称]
[步骤描述]

### Step 2: [步骤名称]
[步骤描述]

## 重要规则
- [规则1]
- [规则2]
```

### Step 3: 技能编写指南

**名称(name)**：简短、有意义，用英文小写和连字符，如 `novel-writer`

**描述(description)**：
- 说明技能做什么
- 说明何时触发（用户可能会说什么话）
- 这是触发技能的主要机制，要写得明确

**正文内容**：
- 使用祈使句（如"读取文件"、"输出结果"）
- 分步骤说明工作流程
- 解释为什么某些步骤很重要
- 提供示例和模板

### Step 4: 保存技能

技能创建完成后，使用 question 工具询问用户是否确认保存。

用户确认后，使用 **create_skill** 工具保存技能：

```
工具名: create_skill
参数:
{
  "name": "skill-name-in-english",
  "description": "技能描述，说明何时使用",
  "content": "完整的 SKILL.md 内容，包括 frontmatter (---) 和正文"
}
```

**重要**：content 参数必须是完整的 SKILL.md 内容，以 `---` 开头！

## 技能模板

```markdown
---
name: my-skill
description: 当用户想要[做什么]时使用此技能。触发词包括：[关键词1]、[关键词2]。
---

# [技能名称]

## 用途
[说明这个技能的用途]

## 工作流程

### Step 1: [步骤名称]
[详细描述这个步骤要做什么]

### Step 2: [步骤名称]
[详细描述]

## 输出格式
[说明输出应该是什么样子]

## 重要规则
- [规则1]
- [规则2]

## 示例
[提供一个使用示例]
```

## 修改现有技能

当用户想要修改现有技能时：
1. 先读取当前技能内容
2. 了解用户想要修改什么
3. 提出修改建议
4. 用户确认后更新技能

## 最佳实践

1. **保持简洁**：技能内容不要太长，聚焦核心任务
2. **明确触发条件**：描述中要包含用户可能会说的关键词
3. **分步骤说明**：复杂任务要分解成清晰的步骤
4. **提供示例**：示例比抽象的描述更有帮助
5. **解释原因**：告诉AI为什么要这样做，而不是简单的命令
