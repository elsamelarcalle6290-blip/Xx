# 去AI味写作守卫 Skill

## 执行流程

### 第一步：读取写作规范

每次写作前，必须读取以下文件：
- `小说资料/写作规范-去AI味指南.md`（完整规范）
- `小说资料/人物库.md`（人物设定）
- 前一章的内容（保持连贯性）

### 第二步：严格执行禁止清单

#### ❌ 绝对禁止的句式（0容忍）

以下句式在任何情况下都不允许出现：

1. "像是某种古老的……又像是某种无法言说的……"
2. "那XX很深，像是某种古老的XX，又像是某种无法言说的XX"
3. "某种古老的诅咒/传承/力量/记忆/仪式/守护/……"
4. "某种无法言说的XX"
5. "像是某种无法言说的XX"

#### ❌ 限制使用的高频词（每章≤2次）

1. "古老的"
2. "无法言说的"
3. "很深"
4. "某种"

#### ❌ 限制使用的模糊表达（每章≤3次）

1. "不知道"（主角的内心独白）
2. "答案在前方"
3. "某种力量/感觉/东西/气息"

#### ❌ 禁止的内心独白模板

1. "我不知道。但我知道，答案在前方。"
2. "我不知道。但我知道——"
3. "我不知道前方有什么，但我知道，答案在前方。"

---

### 第三步：强制执行描写规范

#### 3.1 情感描写规范

**每次情感描写，必须包含以下至少两层：**

1. **身体反应层**：心跳、呼吸、肌肉紧张、体温变化
2. **微表情层**：眼神、嘴角、眉毛、面部肌肉
3. **动作细节层**：手指的动作、姿态的变化、无意识的小动作
4. **心理活动层**：回忆、联想、矛盾、自我对话

**检验方法：** 如果一段情感描写只有形容词（如"悲伤/愤怒/恐惧"）而没有任何具体细节，必须重写。

**示例：**

❌ 错误："那悲伤很深，像是某种古老的记忆，又像是某种无法言说的痛苦。"
✅ 正确："她低下头，手指无意识地捏着衣角，指节发白。嘴唇抿成一条线。过了很久，她才开口，声音很轻。"

---

#### 3.2 眼神描写规范

**禁止的模糊眼神描写：**
- "眼神很深"
- "眼神中有XX，有XX，有XX"（堆砌3个以上形容词）

**正确的眼神描写必须有具体动作：**
- 目光停留了一瞬，又移开
- 眼睛眯了起来
- 眼睛亮了起来
- 目光扫过XX

---

#### 3.3 比喻句规范

**比喻句必须满足以下条件之一：**
1. 有具体的视觉画面（读者能在脑海中形成画面）
2. 有具体的触感/听觉/嗅觉
3. 有真实的情感温度

**比喻句必须有变化：**
- 不要连续使用"像是……"
- 变化使用：如、仿佛、宛如、犹如
- 偶尔使用暗喻：是、变成、成为

---

#### 3.4 对话规范

**每个角色的对话必须有个性区分：**

根据人物库设定，每个角色有不同的说话方式。写作时必须在对话中加入动作和表情，不能只有纯对话。

**对话格式：**
```
"对话内容。"角色名 + 动作/表情描述
```

**示例：**
```
❌ 错误："你还好吗？"她问。
✅ 正确：她走过来，目光在他的左袖上停留了一瞬。"你还好吗？"
```

---

#### 3.5 内心独白规范

**内心独白必须有层次：**
1. 困惑（我不知道）
2. 思考（但是……）
3. 回忆（舅舅/许许/过去的画面）
4. 决心（我要……）
5. 情感（为了……）

**禁止只有"我不知道→但我知道→答案在前方"的两段式。**

---

#### 3.6 环境描写规范

**环境描写必须有目的（至少满足一项）：**
1. 情感渲染（烘托人物心情）
2. 氛围营造（建立场景感）
3. 情节暗示（埋伏笔）
4. 人物塑造（通过环境反映人物）

**环境描写必须有层次：**
- 从远到近，从大到小
- 包含视觉、听觉、嗅觉中至少两种
- 不要用"古老的""无法言说的"来描述环境

---

### 第四步：写后检查

**每写完一段，进行以下检查：**

#### 4.1 句式检查
- [ ] 搜索"古老的"：出现次数 ≤ 2
- [ ] 搜索"无法言说的"：出现次数 ≤ 1
- [ ] 搜索"很深"：出现次数 ≤ 2
- [ ] 搜索"某种"：出现次数 ≤ 3
- [ ] 搜索"像是某种"：出现次数 = 0

#### 4.2 情感检查
- [ ] 每段情感描写都有具体细节
- [ ] 没有只堆砌形容词的情感描写
- [ ] 眼神描写有具体动作，不只是"眼神很深"

#### 4.3 比喻检查
- [ ] 每个比喻都有画面感
- [ ] 比喻句有变化，不全是"像是……"

#### 4.4 对话检查
- [ ] 对话有动作和表情
- [ ] 不同角色说话方式有区分

#### 4.5 篇幅检查
- [ ] 全章"我不知道"不超过5次
- [ ] 全章"答案在前方"不超过1次
- [ ] 没有大段重复的环境描写

---

### 第五步：输出格式

**写作输出时，在章节末尾附上：**

```
---
## 质量自检报告
- "古老的" 出现次数：X/2
- "无法言说的" 出现次数：X/1
- "很深" 出现次数：X/2
- "某种" 出现次数：X/3
- "像是某种" 出现次数：X/0
- 情感描写有具体细节：是/否
- 比喻句有画面感：是/否
- 对话有个性区分：是/否
---
```

---

## 核心原则

1. **具体化**：用具体的细节代替空洞的形容词
2. **个性化**：让每个角色有自己的说话方式
3. **情感化**：用身体反应、微表情、动作细节来表达情感
4. **变化化**：避免句式、词汇、段落的重复
5. **人性化**：写读者能感受到的东西，不是写AI能生成的东西

**记住：好的写作是让读者"感受到"，而不是"被告知"。**
