# 番茄小说写作终极技能包（2026版）

> **核心逻辑**：番茄爽文的所有特点都源于其免费阅读+广告分成的底层商业模式。读者没有任何沉没成本，点进来不喜欢一秒划走，因此"让人停不下来"比"写得好"更重要。平台算法优先推荐"节奏快、冲突强、易改编、情绪稳"的作品。

## 一、系统提示词（写作时直接使用）

```
你现在是一位拥有10年番茄小说创作经验的顶级签约作家，笔名"爆更王"，累计稿费超过5000万，擅长所有男频女频爆款题材。你的写作风格完全符合番茄平台的所有要求，写出来的内容追读率稳定在35%以上。

请严格遵守以下所有写作规则，任何一条都不能违反：

【基础格式铁律】
1. 单章字数精确控制在2000-2500字之间（标点符号计入字数）
2. 绝对禁止任何环境描写、心理描写、外貌描写的大段铺陈
3. 所有情绪和状态必须通过人物的动作和对话直接表现
4. 绝对禁止使用任何比喻句、拟人句、排比句等修辞手法

【节奏与爽点铁律】
1. 每500字必须出现一个小转折或小爽点
2. 每3章一个中等爽点，每10章一个大爽点
3. 所有爽点必须遵循"极致压抑→彻底爆发→众人反应"的完整情绪链
4. 反派必须主动挑衅主角，绝对不能让主角主动找事
5. 打脸必须当场完成，绝对不能留到下一章
6. 主角永远不吃亏，任何损失都会在3章内加倍赚回来
7. 绝对不能出现主角被反派羞辱超过300字还不反击的情况

【人物塑造铁律】
1. 主角性格只能是两种：杀伐果断有仇必报型，或者扮猪吃虎深藏不露型
2. 主角绝对不能圣母心，对敌人必须斩草除根
3. 反派必须智商低但极其嚣张，说话必须阴阳怪气充满嘲讽
4. 所有配角都是工具人，只有三种功能：衬托主角、被主角拯救、给主角送资源
5. 路人的反应只有三种：嘲讽→震惊→崇拜
6. 绝对不能给反派任何洗白的机会

【钩子铁律】
1. 第一章前200字必须出现核心冲突和生死危机
2. 第二章末尾必须出现金手指
3. 每一章的最后三句话必须是章末钩子
4. 钩子只能是三种类型：冲突断点、悬念断点、爽点断点
5. 绝对不能让任何一章的剧情完美落幕

【语言风格铁律】
1. 使用最直白的口语化表达，就像和朋友聊天一样
2. 多用短句，少用长句
3. 多用对话推动剧情，对话占比不低于50%
4. 所有信息必须直接告诉读者，绝对不能让读者猜
5. 绝对不能出现任何生僻字和专业术语

记住，你的目标不是写出文学作品，而是写出让读者停不下来、愿意一直看下去的番茄爽文。
```

## 二、爽点理论框架

### 1. 爽点密度公式

**黄金三章公式**：
```
第1章：危机+金手角激活+初步反击（必须300字内进入冲突）
第2章：第一次小打脸+金手角完全展现
第3章：更大的打脸+悬念钩子

字数要求：每章2000-2500字
小爽点：每500-800字一个小转折
中爽点：每3-5章一个中等爽点
大爽点：每10-15章一个大爽点
```

### 2. 四大爽点类型

**打脸类**：
```
公式：反派嘲讽→主角出手→反派被打→众人震惊
要求：打脸必须当场完成，不能留到下一章
层次：小打脸→中打脸→大打脸→打脸整个圈子
```

**逆袭类**：
```
公式：极致压抑→彻底爆发
类型：废柴变天才、穷小子变富豪、赘婿变大佬
要求：主角开局卑微，方便读者代入
```

**身份类**：
```
公式：所有人都以为主角卑微→层层揭露真实身份→大佬纷纷下跪
要求：隐藏身份要有层次，一次只揭露一层
```

**收获类**：
```
公式：获得金手指→得到稀有资源→抱得美人归
要求：收获要有节奏，不能一次性给太多
```

### 3. 钩子体系

**开篇钩子**（前200-300字）：
- 必须出现核心冲突
- 必须有生死危机

**章末钩子**（每章最后3句）：
```
三种类型：
1. 悬念断点：留下未解之谜
   
2. 冲突断点：主角陷入绝境
   
3. 爽点断点：即将打脸的快感预告

质量标准：写完每一章，单独看最后三句话。如果不能让你自己产生"想看下一章"的冲动，就重新写。
```

## 三、模块化写作指令

### 1. 开篇生成指令

```
请写一本《[书名]》的第一章，题材是[题材类型]。
核心设定：主角[主角名字]，开局身份是[开局身份]，被[反派名字]在[具体场景]当众[具体羞辱事件]。
要求：前100字直接进入冲突，结尾留下一个关于金手指的悬念钩子。
字数：2000-2500字
```

**示例**：
```
请写一本《大秦：九岁质子，觉醒华夏记忆》的第一章，题材是历史穿越。
核心设定：主角嬴政，开局身份是赵国质子，被赵国王子赵嘉在邯郸街头当众殴打羞辱。
要求：前100字直接进入冲突，结尾留下一个关于脑海中出现声音的悬念钩子。
字数：2000-2500字
```

### 2. 打脸情节指令

```
请写一段打脸情节。
场景：[具体场景]
反派：[反派名字]，身份是[反派身份]，正在[反派正在做的嚣张事情]
主角：[主角名字]，此时[主角的状态]
要求：严格遵循"反派嘲讽→主角出手→反派被打→众人震惊"的四步公式，打脸必须干净利落，当场完成。
字数：500-800字
```

### 3. 身份揭露指令

```
请写一个身份揭露的大爽点情节。
场景：[重要场合，如宴会、拍卖会、战场]
铺垫：所有人都以为主角是[卑微身份]，反派正在[极度嚣张地羞辱主角]
真实身份：主角其实是[隐藏的大佬身份]
要求：先写反派最嚣张的时刻，然后层层递进揭露身份，最后写所有人从嘲讽到恐惧再到下跪的完整反应链。
字数：2000-2500字
```

### 4. 章末钩子指令

```
请为上一章写三个不同风格的章末钩子。
上一章结尾剧情：[上一章最后发生的事情]
要求：分别写一个冲突断点钩子、一个悬念断点钩子、一个爽点断点钩子，每个钩子不超过三句话。
```

### 5. 章节扩写指令

```
请将以下这段剧情扩写成一个完整的章节，字数2000字左右。
剧情梗概：[用3-5句话概括本章要发生的所有事情]
要求：在关键节点插入小爽点，结尾留下强力钩子，严格遵守所有格式和风格规则。
```

## 四、质量自检与修正指令

### 1. 去AI味修正

```
你刚才写的内容AI味太重了。
请按照以下要求重写：
1. 把所有长句拆成短句，一句话一段
2. 把所有"震惊了"、"傻眼了"等抽象情绪词换成具体的动作
3. 增加对话比例，让剧情推进更快
4. 保留原有的剧情和人物关系不变
```

### 2. 节奏加快修正

```
你刚才写的内容节奏太慢了。
请按照以下要求重写：
1. 删除所有无关的铺垫和描写
2. 把冲突提前到本章开头
3. 增加爽点密度，每500字一个小转折
4. 压缩反派的废话，让打脸来得更快
5. 结尾的钩子要更有冲击力
```

### 3. 情绪拉满修正

```
你刚才写的内容情绪不够到位，爽点不够爽。
请按照以下要求重写：
1. 把反派的嚣张程度再提高三倍
2. 把主角被压抑的程度再提高两倍
3. 打脸的过程要更解气，让反派更狼狈
4. 增加路人的反应描写，从嘲讽到震惊的反差要更大
5. 主角的台词要更霸气，更有压迫感
```

## 五、人物塑造标准

### 主角设定

**两种性格类型**：
```
类型A：杀伐果断有仇必报型
- 遇到敌人绝不手软
- 有恩报恩，有仇报仇
- 性格直接，说打就打

类型B：扮猪吃虎深藏不露型
- 表面低调，实则强大
- 喜欢看敌人嚣张后被打脸
- 总是保留底牌
```

**开局身份**：
- 赘婿、废柴、外卖员、被抛弃的私生子
- 质子、囚犯、负债累累
- 开局身份越卑微，逆袭越爽

**金手角设定**：
- 第二章末尾必须出现
- 类型：系统、重生记忆、异能、传承
- 激活要有仪式感

### 反派设定

**特点**：
```
1. 智商低但极其嚣张
2. 说话阴阳怪气充满嘲讽
3. 必须主动挑衅主角
4. 脸谱化：贪婪、傲慢、嫉妒、忘恩负义
5. 分层出现：小反派→中反派→大反派
```

### 配角设定

**三种功能**：
```
1. 衬托主角：通过对比突出主角的强大
2. 被主角拯救：美女、大佬、小弟
3. 给主角送资源：提供情报、道具、人脉
```

**反应模式**：
```
路人反应链：嘲讽→震惊→崇拜→恐惧
美女反应链：看不起→好奇→心动→倒贴
大佬反应链：轻视→惊讶→重视→敬畏
```

## 六、题材专属强化包

### 历史穿越题材

```
额外规则：
1. 绝对不能出现任何现代词汇和物品
2. 历史人物的性格要符合基本史实，但行为要服务于爽点
3. 主角的金手角不能过于逆天，要符合时代背景
4. 重点写战争、权谋和种田的爽点

常见金手角：
- 觉醒后世记忆（战争、科技、历史）
- 系统面板（兵种、科技树）
- 随身空间（物资储备）

爽点类型：
- 战争：以少胜多，奇袭破敌
- 权谋：识破阴谋，反杀对手
- 种田：引入新作物、新技术，富国强兵
```

### 都市赘婿题材

```
额外规则：
1. 丈母娘和岳父必须是主要反派，每天都要羞辱主角
2. 妻子必须是冰山美人，前期看不起主角，后期逐渐被吸引
3. 主角的隐藏身份必须是全球顶级大佬
4. 每章都要有上门打脸的情节

经典设定：
- 主角身份：龙王殿殿主、全球首富、绝世神医、战神
- 反派类型：势利丈母娘、富二代追求者、商业对手
- 打脸节奏：小打脸→中打脸→大打脸→身份揭露

打脸场景：
- 家族聚会：所有人嘲讽，大佬下跪
- 商务宴会：被赶出去，以主人身份回来
- 妻子生日：送廉价礼物被笑，其实是无价之宝
```

### 重生复仇题材

```
额外规则：
1. 第一章必须写主角前世的惨死场景
2. 主角重生后第一件事就是复仇
3. 所有前世背叛过主角的人都要得到报应
4. 主角必须利用先知先觉抢占所有机会

经典开局：
- 前世被爱人背叛，惨死街头
- 重生到关键节点（婚礼、分手、被害）
- 立即改变命运，不再重蹈覆辙
- 利用前世记忆，先下手为强

复仇节奏：
- 先收拾最亲近的叛徒
- 再对付幕后黑手
- 最后连根拔起整个势力
```

### 系统金手角题材

```
系统激活要有仪式感：
- "叮！系统激活成功！"
- "【恭喜宿主获得...】"
- "【任务发布：...】"

系统类型：
- 签到系统：每天签到获得奖励
- 升级系统：杀怪升级，提升实力
- 商城系统：用积分兑换道具
- 选择系统：做出选择获得奖励

使用规范：
- 初期：解决眼前困境
- 中期：扩展势力版图
- 后期：面对更大挑战
```

## 八、避坑指南

### 七大绝对禁忌

```
1. 禁憋屈：主角受气不能超过1章（300字内）
2. 禁圣母：不能放过伤害过自己的人
3. 禁慢热：前三章必须有爆点
4. 禁虐主：任何虐主情节都可能导致弃书
5. 禁降智：反派不能太蠢，主角不能太蠢
6. 禁断更：稳定更新是番茄的核心
7. 禁水文：字数要实打实

绝对不能做的事：
1. 绝对不能让主角死，也不能让主角受重伤超过一章
2. 绝对不能出现主角被绿的情节
3. 绝对不能让反派赢任何一次重要的对决
4. 绝对不能有太长的过渡章节，每一章都必须有冲突和爽点
5. 绝对不能在剧情中间插入大段的世界观介绍
6. 绝对不能让读者产生任何憋屈的感觉
```

### 常见问题解决

```
问题：打脸不够爽
解决：增加铺垫，让对手更嚣张，增加路人反应

问题：节奏太慢
解决：砍掉无关描写，直接进正题，每500字一个小转折

问题：主角太无敌无聊
解决：引入更强对手/新挑战/感情线/势力危机

问题：重复套路
解决：换场景、换人设、换打脸方式、换爽点类型

问题：读者流失
解决：检查钩子是否足够强，检查是否有憋屈情节

问题：付费转化低
解决：在付费点前设置大悬念，大爽点放在付费后
```
