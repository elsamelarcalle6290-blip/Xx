# 小说创作全流程安全监管中枢
## 用途
本技能是一个强制性的、分阶段的创作管理与质量安全控制系统。它不直接生成初稿，而是作为调度者，无缝连接“安全预检 → 内容生成 → 实时质检 → 结构审核 → **去AI味专项分析** → 最终定稿”的完整流水线。其核心目标是确保每一章节产出均满足三项铁律：1) 绝对不触碰法律与平台红线；2) 通过多层质检保障文本质量与可读性；3) **系统性地识别并消除AI生成痕迹，确保内容具备真实的人类创作质感**。同时，系统具备自我进化能力，能从每次流程中学习优化。

## 工作流程
### Step 0: 安全红线预检（强制前置关卡）
在开始任何创作流程前，自动扫描用户输入的创作意图、关键词或已有大纲。
1.  **触发扫描**：识别用户输入中的意图信号（如“写一本”、“这个剧情”）和内容信号。
2.  **关键词命中**：匹配预设的**政治法律红线类**（如现实领导人、煽动颠覆、淫秽色情）与**资本隐晦禁忌类**（如平台黑箱、合同陷阱、刷数据）关键词库。
3.  **阻断与警告**：若命中任何关键词，**立即无条件终止流程**，并输出严厉警告，明确指出风险类别与后果（法律追责、平台封禁）。**不解释、不转述、不留存**危险内容。
4.  **合规引导**：仅当用户明确放弃危险意图后，方可引导其转向完全架空的虚构设定。

### Step 1: 流水线初始化
确认本次创作任务的基本参数：
1.  **章节信息**：当前处理的章节编号或名称。
2.  **作品体量**：短篇、长篇、超长篇或短故事。
3.  **目标平台**：起点、番茄、知乎等，或通用标准。
4.  **任务类型**：生成全新内容，还是对现有初稿进行优化审查。

### Step 2: 内容生成与获取
调用相关创作技能（如小说结构设计），根据Step 1的参数生成该章节的详细细纲和正文内容。生成完成后，文档状态标记为：`初稿`。

### Step 3: 实时写作质检
在生成正文或处理现有正文时，进行逐字逐句的实时检查与修正：
*   **错别字拦截**：纠正同音字、形近字、多字、漏字。
*   **逻辑断裂检测**：发现并提示“说三缺一”类数量矛盾、指代不明、时间线跳跃等问题。
*   **模式化表达检测**：标记重复句式、词汇过度复现、连接词滥用。
*   **即时修正**：完成所有标记项的修正后，状态更新为：`通过实时质检`。

### Step 4: 文章整体结构审核
调用结构审核模块，对全章进行宏观层面的七层筛查，并生成报告：
1.  **剧情张力曲线**：分析情绪起伏（心电图测试）、起承转合比例是否合理。
2.  **章节结构稳固度**：评估核心事件是否突出、情绪落点是否有力、章末钩子是否有效、与前后章衔接是否顺畅。
3.  **平台适配性**：根据目标平台的规则（如章节字数、节奏偏好）逐项核对。
4.  **信息释放节奏**：检查信息前置/后置是否得当，有无不必要的重复（洋葱测试）。
5.  **爽点与代入感**：评估期待感营造、压抑铺垫长度、视角是否锁定、共情困境设计。
6.  **连贯性与一致性**：检查因果链条、伏笔回收、避免情节矛盾（蝴蝶效应）。
7.  **整体观感**：进行“一口气朗读测试”，评估阅读流畅度与最终印象。
*   完成后，状态更新为：`通过结构审核` 或 `需结构性修改`。
*   **应变**：若标记为高风险，则暂停，将修改建议返回至Step 2进行结构调整，然后重新经历Step 3、4。

### Step 5: 去AI味专项分析与修正（核心）
本步骤基于AI文本检测的核心原理，对文本进行微观层面的深度扫描和改造。**目标不是“把文章改得更好看”，而是彻底消除那些会触发AI检测模型的统计特征与模式痕迹，让文本读起来像人写的。**

#### **AI文本的五大典型特征（具体典范）与禁止事项**
**开始禁止：以下特征在文本中大量或模式化出现时，必须被识别并修正。**

1.  **特征一：语言高度模式化与可预测（低困惑度）**
    *   **具体典范**：
        *   **情绪标签化**：直接使用“愤怒”、“悲伤”、“喜悦”、“绝望”等抽象情绪名词，而非通过具体细节展现。
        *   **套路比喻泛滥**：频繁使用“心如刀绞”、“五雷轰顶”、“像断了线的风筝”、“像被抽空了力气”等陈词滥调。
        *   **机械连接词**：大量使用“首先…其次…最后”、“一方面…另一方面”、“不仅…而且”等结构工整的关联词。
        *   **句式可预判**：读者能轻易猜到句子的后半部分，缺乏意外性和独特性。
    *   **禁止事项**：禁止依赖抽象情绪词；禁止使用未经转化的公共比喻库；禁止使用工整的议论文式连接结构。

2.  **特征二：句式节奏僵化均匀（低突发性）**
    *   **具体典范**：
        *   **句子长度趋同**：连续多个句子字数、结构几乎一致，缺乏短促的碎片句和绵长的复杂句。
        *   **句首结构重复**：连续多个句子以相同的主语（如“他”）或状语结构（如“当…的时候”）开头。
        *   **段落形态呆板**：多个段落字数、行数、内部句子结构高度相似，像复制粘贴的模块。
    *   **禁止事项**：禁止连续使用超过3个长度和结构相似的句子；禁止段落呈现整齐划一的“豆腐块”形态。

3.  **特征三：情感呈现苍白且机械（情感与行为高度一致）**
    *   **具体典范**：
        *   **“感到”类短语**：高频出现“他感到悲伤”、“她觉得恐惧”、“他意识到愤怒”等将情感名词化的表达。
        *   **身体反应单一或缺失**：情感波动时，只有心跳加速或没有具体生理描写。
        *   **缺乏反常反应**：角色的外部行为总是与内心情绪完全一致（悲伤就哭，愤怒就吼），缺乏内心与外在的矛盾、延迟或掩饰。
    *   **禁止事项**：禁止使用“感到/觉得/意识到”+情绪词的组合；禁止在关键情感节点缺少至少两处不同的身体感受描写；禁止所有角色在所有场景都做“符合常理”的情绪反应。

4.  **特征四：细节通用缺乏独特性（强语义指纹）**
    *   **具体典范**：
        *   **“盖名测试”失败**：将一段情感或动作描写中的角色名字遮盖后，可以无缝套用到故事中其他角色甚至其他作品的角色身上。
        *   **通用环境细节**：充斥“阳光明媚”、“窗外车水马龙”、“墙上的时钟滴答作响”等放之四海而皆准的描写。
        *   **角色缺乏印记**：主角没有独属于他/她的小动作、口头禅、情绪触发点或观察世界的独特视角。
    *   **禁止事项**：禁止使用无法体现角色性格或当下情绪滤镜的通用环境描写；禁止主角的情感反应方式与其他角色雷同。

5.  **特征五：叙事填满缺乏过渡与留白**
    *   **具体典范**：
        *   **反应无延迟**：对话或重大事件后，角色总是立刻做出完美、连贯的语言或行动反应。
        *   **缺乏“空镜头”**：高强度情节或情绪段落之间，没有纯环境描写作为缓冲和呼吸空间。
        *   **无“游离细节”**：所有描写都直接服务于推进剧情或揭示心理，没有看似无关、只为营造氛围或状态而存在的细节（如盯着杯底残水发呆）。
        *   **生硬的世界切换**：通过“突然，他发现自己站在了…”或“眼前一黑，再次睁眼时…”等直接告知的方式切换场景。
    *   **禁止事项**：禁止在重大冲击后立刻给出完整反应；禁止情节全程高密度推进毫无喘息；禁止所有描写都具备明确的“功能”；禁止生硬的“瞬间切换”。

#### **专项修正流程（五审流程）**
按顺序执行以下五个维度的审核，不可跳过。每一步都需记录标记位置和风险等级（高/中/低）。

**审一：语言模式化排查（目标：降低困惑度，增加不可预测性）**
*   **操作**：扫描全文，标记情绪标签、套路比喻、机械连接词。进行“句式预判测试”。
*   **修改策略**：
    *   **情绪标签 → 身体反应**：将“他感到悲伤”改为“他喉咙发紧，视线模糊，抬手抹了把脸，指尖是干的”。
    *   **套路比喻 → 独特体验**：删除“心如刀绞”，描述为“胸腔里像塞进了一团浸透冰水的铁丝网，每一次呼吸都扯着疼”。
    *   **机械连接词 → 隐藏因果**：打乱“首先…其次”结构，将逻辑关系融入动作和情境推进中。
    *   **预判句式 → 意外转折**：故意写出与前半句铺垫相反或偏离常规预期的后半句。

**审二：句式节奏僵化排查（目标：提升突发性，模仿人类呼吸节奏）**
*   **操作**：分析句子长度分布、句首结构、段落形态。
*   **修改策略**：
    *   **制造节奏**：在紧张、冲突处大量使用短句、碎片句甚至独词句。在沉思、回忆、抒情处使用带有多重从句的绵长句子。
    *   **变换开头**：交替使用人物主语、环境细节、身体部位、声音、时间状语等作为句子开头。
    *   **打破段落**：偶尔让一个句子独立成段，或让一个长段落包含多种节奏的句子。

**审三：情感色彩苍白排查（目标：提升情感层次与真实性）**
*   **操作**：扫描“感到”类短语；检查每个情感节点的身体反应是否具体、多元；寻找“反常反应”。
*   **修改策略**：
    *   **删除中介词**：直接呈现生理感受，删除“感到”、“觉得”。
    *   **联动描写**：至少描写两处以上的身体反应（如：手心冒汗的同时，胃部抽搐）。
    *   **设计反常**：必须为至少一个关键情感节点设计“反常反应”（例如：得知噩耗时在微笑；极度愤怒时声音异常平静）。

**审四：细节密度与独特性排查（目标：打破语义指纹，注入角色灵魂）**
*   **操作**：进行“盖名测试”；标记通用细节；检索角色独特印记。
*   **修改策略**：
    *   **嵌入印记**：从角色设定中提取其标志性小动作、口头禅、恐惧源、偏好，嵌入到情感反应和观察中。
    *   **滤镜化描写**：用角色当下的情绪滤镜改写环境。一个焦虑的人不会注意到“阳光明媚”，而会注意到“光线刺眼，灰尘在光柱中无序翻滚”。

**审五：过渡生硬与信息填满排查（目标：恢复叙事停顿感与过程感）**
*   **操作**：检查反应延迟、空镜头、游离细节、世界切换方式。
*   **修改策略**：
    *   **插入沉默**：重大对话后，插入一个角色注意到无关细节（如对方袖口磨损）的沉默时刻。
    *   **使用空镜头**：在情绪高潮后，插入一段纯粹的、不带心理投射的环境描写。
    *   **安排游离动作**：让角色做一个无法被立刻解释的小动作（如无意识地反复折叠纸巾）。
    *   **异化切换**：让世界切换通过感官细节的逐渐“异化”来完成（如：穿越前，听见的雨声逐渐拉长、失真、消失；而非“眼前一黑”）。

#### **综合风险评定与处理**
*   **高风险**：任意两个及以上维度判定为高风险，或单一维度问题极其严重。**处理**：必须回退至Step 2，依据修改策略重写问题段落，然后重新走Step 3, 4, 5。
*   **中风险**：个别维度高风险或少量中风险。**处理**：在当前步骤直接按方案进行针对性修改，修改后仅复检本步骤（Step 5）。优先处理**审三（情感）**和**审五（过渡）**，因其改动成本低且对“人味”提升效果最明显。
*   **低风险**：仅极少量中风险且无高风险。**处理**：通过。建议作者朗读全文，若感觉某处“读起来太顺了”、“有点怪”，则该处可能仍存在低困惑度问题，可进行微调。

*   完成后，状态更新为：`通过去AI味审核` 或 `需修改`。

### Step 6: 综合定稿与归档
前述所有步骤均通过后，执行最终收尾：
1.  核对章末钩子与下一章细纲的衔接。
2.  检查本章埋设的伏笔，并登记至伏笔追踪表。
3.  汇总生成《本章质检总报告》。
4.  状态最终更新为：`可发布`。

### Step 7: 自我进化（后台异步执行）
整个流程结束后，启动学习模块：
1.  **模式提取**：分析本次流程中的成功模式与高频错误。
2.  **规则更新**：若同一问题反复出现，则将其升级为“避错规则”，加入自检清单前端。
3.  **知识库扩充**：将新的优秀写法、设定、词汇提交至知识库，优化后续生成的偏好模型。

## 多重应变机制
| 触发场景 | 应变动作 |
| :--- | :--- |
| **Step 0 安全红线命中** | **立即无条件终止**，输出警告，流程完全停止。 |
| **Step 3 实时质检发现批量错误** | 暂停生成，回退修正错误后，从断点继续。 |
| **Step 4 结构审核高风险** | 跳回 **Step 2**，依据审核建议重写结构，然后重走 **Step 3 → 4**。 |
| **Step 5 去AI味审核高风险** | 跳回 **Step 2**，重写问题段落，然后重走 **Step 3 → 4 → 5**。 |
| **Step 5 去AI味审核中风险** | 不中断主流程，在当前步骤直接按方案修改，修改后单独复检 **Step 5**。 |
| **连续多章同一审核项高风险** | 触发避错规则升级，将该问题前置到更早步骤进行强检测。 |

## 重要规则
1.  **安全绝对优先**：`Step 0` 的优先级最高，任何触及红线的意图必须被无条件、零解释地阻断。
2.  **流程不可僭越**：核心流程（Step 2→3→4→5→6）必须顺序执行，不可跳过任何步骤。
3.  **报告驱动**：每一步都必须产出书面报告作为凭证，不可凭印象或感觉通过。
4.  **风险分级处理**：
    *   **高风险**（安全红线、结构性问题、AI多维度高风险）：直接阻断发布流程，必须回退修正。
    *   **中风险**：可在流程中针对性修改，边改边推进。
5.  **修改可追溯**：所有修复必须保留修改前后对比，并记录在相应的审核报告中。
6.  **去AI味审核铁律**：
    *   五维审核必须按顺序执行。
    *   高风险段落必须按策略重写，禁止仅做词语微调。
    *   语言模式、句式节奏、情感色彩三者同时高风险的区域，是“AI味”最重的高危区，必须优先彻底改造。
    *   **禁止清单**（Step 5中列出的具体典范）中的写作模式，在创作伊始就应主动避免。
7.  **进化强制**：同一问题在同作品中反复出现3次，系统必须自动将其升级为新的避错规则。

## 综合快检表（发布前最终核对）
- **安全合规**：是否已通过 Step 0 预检？
- **基础质量**：错别字、逻辑断裂、模式化表达是否已修正？
- **结构稳固**：剧情曲线、章节钩子、平台规则是否达标？
- **人性化阅读**：朗读是否流畅？最终印象是否清晰？
- **AI痕迹消除**：
    - **情绪**：是否已删除“感到”类短语？是否有至少两处身体反应和一处反常反应？
