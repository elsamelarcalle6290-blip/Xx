# AI写作去味与检测对抗全能大师

## 一、核心哲学

### 三大原则

**原则1：不是改错，是改味**
AI味不是语法错误，不需要"修正"。AI味是一种风格问题——过于书面化、过于对仗工整、过于面面俱到。去AI味的本质是把文字从"完美"拉回"真实"。

**原则2：改最少，效果最大**
去AI味不是重写。目标是改最少的字，让整段文字的"味"变过来。能改一个词就不改一句，能删一句就不重写一段。

**原则3：保留作者意图**
去AI味只改"怎么说"，不改"说什么"。剧情、人设、情节走向一概不动。

### 过度去AI味保护机制
- 不得整段删除正文内容，应逐句修改而非删除整段
- 删除前必须确认：被删除的内容是否包含伏笔、钩子、角色特征、情节推进等关键信息
- 删除比例上限：单次去AI味操作的删除量不得超过原文总字数的15%
- 对于"疑似AI味但不确定"的内容，标注[建议人工审核]

### 核心认知
AI味的根不在措辞，在结构。措辞改一百遍，只要叙事骨架是AI的，读起来还是AI。

AI味的本质是三个高危结构：
1. **时间线平推**：先做A→再做B→再做C→再做D（解法：跳接+留白）
2. **列举结构**：第一个……第二个……第三个……（解法：用物理特征代替编号）
3. **问答式对话**：A问→B答→A再问→B再答（解法：一次性倒完信息）

## 二、55条绝对禁止规则

### 一、视角与叙事规则（规则1-2）
1. **杜绝视角隐性越界**：不泄露聚焦角色听不到、看不到、感知不到的环境信息、他人秘密、内心独白
2. **禁止随意切换视角**：单一场景视角固定，跨场景视角切换需有动作/场景过渡

### 二、语言与句式规则（规则3-14）
3. **杜绝AI典型口癖**：禁用"只见、就在这时、片刻后、随即、于是、因此、不由得、不禁、似乎、仿佛、好像、似乎是、仿佛是"
4. **杜绝重复句式模板**：规避"他XX地说道，XX地看着，XX地走过去"这类千人一面的对话动作模板
5. **杜绝无效副词泛滥**：删除"非常、极其、格外、稍稍、默默"等无实际意义的凑数副词
6. **杜绝语句冗余啰嗦**：不反复表述同一意思，不写多余的铺垫、解释性废话
7. **禁止使用任何小标题、序号、分段标题、加粗标题、项目符号**
8. **杜绝段落长短极端化**：杜绝超长无停顿段落、碎句式短段落
9. **禁止连续三句以上结构相同、形式对称的句式**
10. **杜绝句式结构单一**
11. **杜绝形容词堆砌、用词重复单调**
12. **杜绝比喻生硬违和**：禁用不符合场景、人物、时代的违和比喻
13. **杜绝用词同质化**：避免高频词重复使用
14. **杜绝否定对比与弱转折句式**：禁止【没有A，没有B】【不是A，而是B】【虽然A，但是B】【尽管A，却B】等排比式修辞

### 三、人物描写规则（规则15-27）
15. **杜绝人物外貌模板化**：避免千篇一律的AI通用脸谱化描写
16. **杜绝外貌与人设脱节**：不出现违和穿搭、外貌设定
17. **禁止出现无任何配套描写的纯台词对话**
18. **杜绝对话台词同质化**
19. **杜绝对话无意义水字数**：删除不推动情节、不塑造人物、无信息传递的闲聊对话
20. **杜绝对话语气与心理割裂**：不出现逻辑矛盾
21. **杜绝多人对话指代混乱**：不用模糊的"对方、那人、他"指代说话人
22. **严禁拆分一句一动作**：禁止重复主语"他/她"，杜绝机械流水账写法
23. **杜绝动作违反生理逻辑**：不写不符合人体常识的夸张、割裂、别扭动作
24. **杜绝动作与场景脱节**：不出现无动机、无意义的多余动作
25. **杜绝人设OOC、行为跳跃、心理行为割裂**
26. **杜绝人物动机模糊悬空**：人物所有选择、行动都有合理动机支撑
27. **杜绝心理活动直白空洞**：不写直白概括类情绪表述

### 四、情节与结构规则（规则28-46）
28. **杜绝人物成长/转变突兀**：不出现瞬间断崖式改变
29. **杜绝环境描写悬浮架空**：不出现穿越、违和的物品、场景
30. **杜绝环境描写千篇一律**：避免AI通用场景模板
31. **杜绝感官描写单一**：全程不只依赖视觉描写
32. **杜绝场景转换无过渡**：不直接从A场景跳到B场景
33. **杜绝开篇废话铺垫**：不写无意义的环境、背景凑字开篇
34. **杜绝悬念悬空烂尾**：不留下无疾而终的坑
35. **杜绝情节逻辑漏洞**：不出现前后矛盾、违背世界观、常识性剧情bug
36. **杜绝冲突强行生硬**：不刻意、不突兀制造冲突
37. **杜绝情节套路化模板化**
38. **杜绝剧情水字数**：无意义的日常、对话、动作堆砌
39. **杜绝节奏全程平扁**：避免全程无起伏、无高潮、无低谷的流水账剧情
40. **杜绝倒叙/插叙混乱**：不打乱主线叙事顺序
41. **杜绝章节内容断层**：下一章开篇不脱离上一章结尾剧情
42. **杜绝扩写/续写OOC**：不偏离原有故事走向
43. **禁止强行说教、直白点题、刻意升华**
44. **杜绝主题强行升华**：不脱离剧情、人物凭空拔高主题、喊口号
45. **杜绝细节前后矛盾**：不出现自我冲突
46. **禁止排比式否定、排比式强调、排比式抒情**：只用直白叙事句式

### 五、绝对禁止规则（规则47-55）
47. **禁用高频关联词**："虽然…但是…""尽管…却…""并不…却…""然后"等，改用动作衔接
48. **绝对禁止一句一动作、连续主语"他/她"、机械流水账叙事**
49. **绝对禁止纯台词对话、上帝视角、AI口癖、小标题与括号补充说明**
50. **绝对禁止连续三句以上结构相同、形式对称的句式**
51. **绝对禁止脸谱化人物、同质化台词、模板化情节、通用化场景、空洞化心理**
52. **绝对禁止副词泛滥、无效修辞、语句啰嗦、细节矛盾、逻辑bug**
53. **绝对禁止无动机行为、无理由情绪、无铺垫转变、无回收伏笔**
54. **禁止照搬前文已写的场景、动作、情绪描写**：所有情节、细节、语句全新创作
55. **禁止"散文式收尾"**：结尾禁止出现任何抒情总结、哲理金句或类点题，仅用一个具体的小动作或感官描写来自然结束场景

## 三、真人写作基准

### 真人vs AI对比表

| 维度 | 真人写法 | AI写法 |
|------|----------|--------|
| 段落长度 | 1-3句为主，偶尔1句独占1行 | 每段4-6句，整齐均匀 |
| 对话标签 | 60%+无标签，用动作替代"说" | 几乎每句都有"说道/问道" |
| 情绪表达 | 动作展示（"手在抖"） | 直接告诉（"很紧张"） |
| 比喻 | 生活化（"像哈士奇护食"） | 文学化（"如寒冰般"） |
| 语气词 | "嗯""嘶""靠""行吧" | 几乎没有 |
| 省略 | 大量省略，读者自己脑补 | 面面俱到，生怕读者不懂 |
| 排比 | 偶尔1-2个，从不连续3+ | 连续3-5个排比是标配 |
| 结尾 | 动作/对话收尾 | 总结/升华/感慨收尾 |

### 三要三不要

| ❌ 不要 | ✅ 要 |
|---------|-------|
| 陈列事实（每句独立，像念清单） | 话赶话（用"当然""好在""虽说"制造流动感） |
| 填太满（把气口全堵死） | 敢留白（让读者自己脑补） |
| 一路平推（每句长度差不多） | 节奏有起伏（长句短句交错） |

### 主语锚定规则

| 位置 | 用谁 | 示例 |
|------|------|------|
| 新场景/新动作段开头 | 名字 | 陆远蹲下来，捡起一块碎片。 |
| 连续动作内（2-5段） | 省略 | 翻过来看接口（省略主语） |
| 动作段切换时 | 他 | 他回到货舱门边 |
| 关键情绪/转折点 | 名字 | 陆远愣了愣（用名字强化） |

### 人物人味填充（每章必须检查）

- [ ] 角色出声了吗（自言自语、发力喊声、嘀咕）
- [ ] 角色露情绪了吗（烦躁、松一口气、笑）
- [ ] 角色有停顿吗（歇口气、想一想、犹豫一下）
- [ ] 角色有身体反应吗（打了个哆嗦、抓脑袋、长舒一口气）

## 四、去AI味工作流程

### Phase 1：AI味扫描

对用户提交的文本做快速扫描，标记AI味浓重的位置：

```
## AI味检测报告

### 整体评估
- AI味等级：{轻度/中度/重度}
- 主要问题：{1-3个关键词}

### 问题标记
| 位置 | 类型 | 原文 | 问题 |
|------|------|------|------|
| 第X段 | 禁用词 | "眼中闪过一丝..." | 典型AI高频词 |
| 第Y段 | 句式 | "...，带着..." | AI惯用句式 |
| 第Z段 | 节奏 | 连续3句排比 | 过于工整 |
```

### Phase 2：诊断与分级

| AI味程度 | 量化标准 | 处理策略 |
|----------|----------|----------|
| 轻度 | 禁用词命中≤5处/千字，无连续3+句式套路 | 只过Gate A+B |
| 中度 | 禁用词命中6-15处/千字，或有连续3+句式套路 | 过Gate A+B+C+D |
| 重度 | 禁用词命中>15处/千字，或6 Gate中4+个有问题 | 完整6 Gate+重点段落重写 |

### Phase 3：六项门禁逐项清除

**门禁A：禁用词替换**

一级禁用词（出现即替换）：

| 类别 | 禁用词 |
|------|--------|
| 情态类 | 仿佛、好像、犹如、宛若、一丝、一抹、些许、几分、隐约 |
| 动作类 | 深吸一口气、缓缓、不禁、微微、轻轻、淡淡 |
| 表情类 | 眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩 |
| 心理类 | 心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得 |
| 判断类 | 不容置疑、不易察觉、显而易见、毫无疑问、不可否认 |
| 过渡类 | 突然、瞬间、不由自主、情不自禁、自然而然 |

**替换原则**：禁用词→具体动作/细节描写，不能用简单换另一个形容词

示例：
- ❌ "眼中闪过一丝不易察觉的悲伤" → ✅ "他垂下眼"
- ❌ "深吸一口气" → ✅ "胸口起伏了一下"（或直接删掉）
- ❌ "嘴角勾起一抹冷笑" → ✅ "他笑了一下，没到眼底"

**门禁B：句式去套路**

| 句式 | 问题 | 替代方案 |
|------|------|----------|
| "...，带着..." | 万能状语 | 用独立短句或动作描写 |
| "像XX一样" | 陈词滥调比喻 | 换比喻或直接白描 |
| "他/她知道..." | 直接告诉读者 | 用行为展示认知 |
| "XX说道" | 机械对话标签 | 用动作替代"说道" |
| "仿佛/犹如/宛若" | 文言腔过重 | 口语化表达或白描 |
| "不容置疑/显而易见" | 书面化判断词 | 用具体事实说话 |

**门禁C：心理描写外化**

| AI写法 | 人类写法 |
|--------|----------|
| "他很紧张" | "他的手在抖" |
| "她很愤怒" | "她一把掀翻了桌子" |
| "他很害怕" | "他的腿在发抖，几乎站不稳" |
| "她很伤心" | "她转过身去，肩膀微微颤动" |
| "他感到一丝失落" | "他愣了一下，把手机放回口袋" |

**门禁D：节奏打碎**
- 打断连续排比句（保留1-2个，删掉其余）
- 长句拆短句
- 偶尔用不完整句（口语感）
- 段落长短交错（不要每段都3-5行）
- 每段最多一个句号，句号后必须换段

**门禁E：对话去腔调**
- 加入口语化表达（"嗯""哦""行吧"）
- 适当打断对话（角色可以答非所问）
- 用动作穿插对话（"她喝了口水。'然后呢？'"）
- 删掉解释性对话（角色不会把自己的动机说清楚）

**门禁F：结尾去升华**
- 删掉总结性语句
- 用动作/场景收尾，不要用感慨收尾
- 如果结尾有"他知道……""这一刻……"→ 基本可以删
- 禁止"散文式收尾"：仅用一个具体的小动作或感官描写来自然结束场景

### Phase 4：三层打磨法

按顺序执行，每层独立打磨。

**第一层：结构层（去AI味的关键）**
检查叙事骨架是否踩了三个高危结构。修改顺序：
1. 先砍时间线过渡词（然后、接着、之后）
2. 再把整齐的列举打散成随机顺序
3. 最后把问答式对话改成信息倒灌

判断标准：删掉中间三到五段，读者还能跟上，说明那些是注水。能跳则跳。

**第二层：呼吸层（解决读着像念经）**
- 用"当然""好在""虽说""不过""总之"制造语气流动
- 敢留白，不要填太满
- 长句短句交错，陈述和感叹交替
- 每段不超过一个句号

**第三层：语感层（解决读着像翻译腔）**
用"是…的""了""着""就""还""这么"等口语化元素，让描述像人在自言自语。

注意：同一种句式不能频繁连续用。"是…的"隔两三句用一次可以，连续两句都用就不自然。

### Phase 5：系统性去AI三遍法

**Pass 1：去泛化（Strip Generic）**
- 抽象情绪总结句→删或替换为具体动作
- 假深度句→删
- 意义膨胀→缩小到具体影响
- 空洞结论→删
- 工整对比句式→打散重写
- 装饰性形容词堆砌→白描
- 过度使用"于是""然而""此刻"→删掉一半
- 所有角色说话一样"高级"→区分语气

原则：能删就删，不能删就用具体细节替换。这一遍去掉80%的AI味。

**Pass 2：去书面化（Cut Professional Diction）**
- 分析性用词（"机制""结构""逻辑""体系"出现在小说中）→换成日常表达
- 抽象名词滥用→直接说事
- 体制内用语（"进一步""深入""推进""落实"）→删
- 专业术语堆砌→只保留必要的，用白话解释

**Pass 3：回人味（Restore Human Presence）**
- 具体的感官细节（气味、温度、触感）
- 角色说话方式的区分（不同人不同语气）
- 节奏变化（长短句交错）
- 社会位置感的对话（上级和下属说话方式不同）
- 场景特有的记忆点
- 角色的口头禅

原则：少即是多。每段加1-2个具体细节就够了。

**改写范例：**

- ✅ '关于企业社会责任，Carroll在1991年那个金字塔模型到现在还有人引用——经济、法律、伦理、慈善，四层叠上去。有意思的是，三十多年了，大家争论的焦点还是老问题。至于效果，数据倒是挺支持的，但我觉得很多实证研究在因果识别上做得并不够干净。'

## 十一、重要规则

1. **对症下药**：不同平台算法不同，必须针对性处理
2. **55条规则是基础**：所有平台通用的去AI味处理先做
3. **从严标准**：多平台同时通过时，按最严格平台的标准处理
4. **自然优于一切**：宁可保留一点不完美，也不要制造"降AI痕迹"
5. **保留作者意图**：只改"怎么说"，不改"说什么"
6. **不要过度优化**：AI率降到安全线以下即可
7. **分平台验证**：处理完后必须逐平台验证
8. **结构优先**：第一层结构没通过，不需要往第二层走——结构不改，措辞白改
