# 人物性格一致性审查引擎

## ⚠️ 最高警告：情节必须服务于人物，而非人物服务于情节

> **90%的AI写崩，都是因为用情节推着人物走，而不是让人物自己走。**
>
> 设定再宏大、节奏再精准、色欲再浓烈——**人物性格写崩了，读者就读不进去了。**
> 
> 读者代入的不是情节，是人物。人物崩了，情节再精彩也是空的。

## 核心原则

### 铁律：每一段情节发展，都必须通过「性格合理性」检验

写正文前，问自己三个问题：

```
① 这个角色在这个时间点（弧光位置），会做出这个行为吗？
   → 不会 → 说明情节在强推人物 → 重写情节或调整行为

② 这个角色的核心信念/核心恐惧/核心欲望，被这段情节尊重了吗？
   → 没有 → 说明OOC风险 → 必须给出合理的「信念动摇」理由

③ 如果读者说"TA不会这么做"，我能用角色的心理地基反驳吗？
   → 不能 → 说明你为了情节牺牲了人物 → 重写
```

### 人物性格 > 情节爽感 > 设定完整性

当三者冲突时，优先级如下：

```
人物性格一致性  >>>  情节爽感  >  设定完整性
```

**为什么？**
- 人物崩了 → 读者代入感归零 → 情节再爽也是别人的故事
- 爽点不够 → 读者觉得平淡但还能看
- 设定有坑 → 大部分读者发现不了

### 人物性格的"弹性区间"

人物不是铁板一块。**同一人物在不同弧光阶段可以有不同行为**，但必须符合以下规律：

```
起点性格 → [经历事件A] → 信念松动 → [经历事件B] → 行为变化 → [经历事件C] → 新行为模式
```

**✅ 合法变化示例（苏晚棠）：**
- Ch 1：不敢抬头看人（起点性格：隐忍）
- Ch 12-15：对下人轻飘飘说了句软刀子话（经历被欺压后的小反击）
- Ch 28：正面接招柳姨娘（经历更多欺压后的成长）
- Ch 40：「带我走」（被逼到绝路的主动）
- Ch 103：打了他一巴掌（情感被逼到极限的爆发）
- Ch 194：「裴家的东西谁也别想动」（完成弧光后的彻底转变）

**❌ 非法变化示例：**
- Ch 1：不敢抬头 → Ch 5：直接当众怼柳姨娘（没有足够的事件积累）
- Ch 28：才学会正面接招 → Ch 30：直接掌掴裴行止（弧光跳跃过大）

### 人物行为的三层验证法（写作时逐层检查）

每一段人物行为，必须从三个层面验证：

```
第一层：这个人会这么做吗？
   ↓ 会 → 进入第二层
   ↓ 不会 → 重写 / 或给出「信念动摇」的合理理由

第二层：这个时间点（弧光阶段）会这么做吗？
   ↓ 会 → 进入第三层
   ↓ 不会（早了/晚了）→ 调整行为强度或弧光节奏

第三层：这个情境下（压力等级）会这么做吗？
   ↓ 会 → ✅ 通过
   ↓ 不会 → 调整情境压力或行为反应
```

### 压力-行为匹配表（本书专用）

同一人物在不同压力等级下，应有不同强度的行为反应：

#### 苏晚棠的压力-行为匹配

| 压力等级 | 行为模式 | 本书示例 |
|:--:|:--|:--|
| 🟢 低（日常相处） | 低头、轻声、躲避眼神 | Ch 1-5 日常应对 |
| 🟡 中（被刁难/被逼迫） | 先忍，忍到极限才软刀子反击 | Ch 12-15 洗衣婆子事件 |
| 🟠 高（被威胁/被触碰） | 僵住、呼吸变浅、不躲但也不回应 | Ch 37 壁咚时的反应 |
| 🔴 极限（情感崩溃/触及核心恐惧） | 爆发式反击/无法控制的生理反应 | Ch 103 打他一巴掌 |

#### 裴行止的压力-行为匹配

| 压力等级 | 行为模式 | 本书示例 |
|:--:|:--|:--|
| 🟢 低（日常处理政务） | 冷脸、话少、高效 | Ch 1-5 日常 |
| 🟡 中（涉及苏晚棠的琐事） | 表面不动，小动作出卖（捻佛珠乱了） | Ch 4 吩咐厨房换菜 |
| 🟠 高（涉及苏晚棠的危险/离开） | 克制裂开，失控边缘 | Ch 37 壁咚/Ch 54 怕她走了 |
| 🔴 极限（她受伤/她被威胁/她可能消失） | 克制完全崩塌，不计后果 | Ch 79 摔酒杯/Ch 131 当众抱她 |

## 本书人物性格速查卡（写每章正文前必读）

### 苏晚棠

```
【核心人格】
外柔内刚·隐忍克制·敏感自卑·骨子里倔强

【三不碰】
1. 不能主动表达爱意（她只会用行动暗示，不会说我爱你）
2. 不能主动触碰（她可以被碰，不会主动碰人——Ch 56例外，那是病后豁出去的一次）
3. 不能主动争取（她习惯等别人给，不是自己去要）

【三可以】
1. 可以被逼到绝路后反击（反击时不留余地）
2. 可以在极限状态下说真话（被逼疯了才会说出真心话）
3. 可以在被保护时展露脆弱（在安全的环境里才会哭）

【弧光触发器】
隐忍 → [被欺压] → 小反击 → [被爱] → 信念松动 → [被伤害] → 缩回 → [再被爱] → 沦陷 → [失去] → 独立

【写作红线】
绝对禁止的行为（写了就是OOC）：
❌ 主动勾引裴行止（她不是沈清晏式的狩猎者）
❌ 用身体做筹码（她不会用这种方式）
❌ 主动说"我爱你"（她只会用行动证明）
❌ 在前期（Ch 1-40）正面硬刚柳姨娘（她还没成长到那一步）
```

### 裴行止

```
【核心人格】
冷峻深沉·克制隐忍·占有欲极强·表面君子·内心疯批

【三不碰】
1. 不能直接表白（他只会用行动说爱，嘴上一句不说）
2. 不能在公开场合越界（直到Ch 131在大理寺门口崩了）
3. 不能承认自己沦陷（Ch 55说"我分不清了"已经是极限）

【三可以】
1. 可以用权力暗中护她（吩咐厨房、敲打柳姨娘、禁足）
2. 可以在失控边缘展露真心（壁咚、摔酒杯、"我以为你走了"）
3. 可以在以为她要消失时放弃克制（送她走前的最后一次拥抱）

【弧光触发器】
冰封 → [她出现] → 裂痕 → [靠近她] → 克制崩塌 → [失去她风险] → 完全失控 → [得到她] → 柔软 → [死亡]

【写作红线】
绝对禁止的行为（写了就是OOC）：
❌ 在Ch 55之前叫她的名字「晚棠」（他不敢叫，叫了就等于承认）
❌ 在Ch 73之前吻她（他还压得住）
❌ 在Ch 131之前在公开场合碰她（他要保护她的名声）
❌ 在Ch 180之前叫她「夫人」（那是临终拜天地时才配叫的）
```

### 沈吟霜

```
【核心人格】
表面温婉·城府极深·被命运碾压过的幸存者

【关键设定】
- 不是主动背叛者：被三皇子用父亲性命胁迫
- 不是纯粹的受害者：后四年确实在为三皇子做事
- 赎罪心理：她后半生都会活在愧疚里

【写作红线】
❌ 不能洗白成纯粹的受害者（她确实做了错事）
❌ 不能黑化成纯粹的恶人（她是被逼的）
❌ 不能写得软弱（她被关了十年还没疯，说明她内心极强）
```

### 青黛

## 每章正文写作前的强制流程

### 第一步：读人物速查卡（2分钟）

```
📌 本章出场角色：
- 苏晚棠 [当前弧光阶段：______（如：隐忍期/成长期/沦陷期/独立期）]
- 裴行止 [当前弧光阶段：______]
- 其他角色：______

📌 本章核心情节：[一句话]

📌 灵魂拷问：这个情节→让苏晚棠/裴行止做的事→ 符合她们当前弧光阶段的行为模式吗？
```

### 第二步：写正文时的三不放过

```
写到一个角色做了某个行为时，问：

❓「TA会这么做吗？」
   → 看人物速查卡"三不碰" → 如果碰了 → 重写

❓「TA现在（弧光阶段）会这么做吗？」
   → 看压力-行为匹配表 → 如果行为强度超出当前阶段 → 调整

❓「TA在读者眼里会OOC吗？」
   → 闭上眼睛想象读者读到这段的表情
   → 如果觉得他们会皱眉 → 重写
```

### 第三步：写完后的人物自检

```
□ 苏晚棠的行为是否符合当前弧光阶段？
   → 如不符 → 标注"此处需要信念动摇的理由" → 补写内心动机

□ 裴行止的行为是否符合当前弧光阶段？
   → 如不符 → 同上

□ 本章有没有让角色做「TA绝对不会做」的事？
   → 如有 → 立即删除并重写

□ 本章的人物对话口吻，符合她们的性格设定吗？
   （苏晚棠轻声细语 / 裴行止话少用词精准 / 青黛嘴甜话多）

□ 如果读者说「TA不会这么做」，我能用心理地基反驳吗？
```

## 最终奥义

> **情节是车，人物是司机。**
> **车可以开得快、开得稳、开得花哨——但如果司机不是那个人，读者一眼就看出是替身。**
>
> **记住：读者追的不是情节，是「这个人会怎么面对这个情节」。**
> **人物一旦OOC，情节再爽也是别人的故事。**
