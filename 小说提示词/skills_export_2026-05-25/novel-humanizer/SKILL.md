# novel-humanizer：高性能小说人类化写作标准

> **目标：高性能 × 流畅 × 可读性强 × 吸引人 × 文笔提升 × 通过AI检测**

---

## 核心哲学

### AI味的根在结构，不在措辞

**结构不改，措辞白改。**

AI写的不是不好，是太好了——好到假。人写东西有毛边、有口语、有跳跃，AI写的太圆滑、太工整、太正确。

---

## 第一部分： 核心红线（通过检测的关键）

### 11条快速硬门槛（必须全部通过）

1. **二分对照壳**：清零「而是」「不是A而是B」「并非A而是B」「不在于A而在于B」
2. **冒号**：全角冒号 `：` 目标 0-2，且只用于直接引语提示语
3. **二人称**：清零「你/你会」，对话中的「你」除外
4. **路标词**：「更关键/更要命/换句话说/事实上/值得注意/总之/与此同时」全文合计 <= 2
5. **AI身份口吻**：清零「作为AI」「截至我的知识」「希望这能帮助你」「接下来我们将」
6. **伪口语化动作词**：清零「拆一拆/盘一盘/捋一捋/聊一聊/划重点/敲黑板」「说白了/本质上/归根结底」
7. **AI高频隐喻**：清零「噪音/信号/底色/光谱/滤镜/解药/土壤/拼图/镜像/路径/窗口/缩影」的比喻义用法
8. **高频分析词**：「拆解/梳理/剖析/解构/聚焦/洞察/深耕/赋能/助力/践行/驱动/构建/打造」不堆叠
9. **AI句式壳**：「一旦……就……」「只有……才……」「无论……都……」「随着……的发展」「正是因为……所以……」全文合计 <= 2
10. **戏剧化揭露修辞**：清零「遮羞布/面具/外衣/揭开真面目/戳穿真相」
11. **极值判断句**：「最残酷的地方在于/最可怕的是/真正可怕的是/讽刺之处在于/更残酷的是」全文 <= 1

## 第二部分：三大高危结构（必须优先处理）

### 高危一：时间线平推
```
先A → 再B → 再C → 再D
```
典型词：「然后」「接着」「之后」「于是」

**解法**：跳接+留白。只写关键画面，中间过渡全砍。

| AI写法 | 人类写法 |
|--------|----------|
| 他把干粮码好。然后拿着净水器去河边。装好滤芯接了水。喝了一口。 | 干粮码好了。净水器试过，水是干净的。 |

### 高危二：列举结构
```
第一个……第二个……第三个……
```
典型特征：用序号或排比框架组织内容

**解法**：用物理特征代替编号（「最沉的那个」「角落里的」），把最重要的放最后。

| AI写法 | 人类写法 |
|--------|----------|
| 第一个打开，是一套厨具。第二个箱子，空气净化器。第三个箱子最沉，是压缩干粮。 | 一套厨具。翻了翻，又开了一个，空气净化器。最沉的那个箱子晃着响，划开一看，干粮。 |

### 高危三：问答式对话
```
A问→B答→A再问→B再答
```
典型特征：对话像FAQ，一板一眼对称推进

**解法**：信息倒灌，中间插动作或反应。

| AI写法 | 人类写法 |
|--------|----------|
| 「这是什么。」「量子封印锁。」「什么意思。」「强制开启会销毁。」 | 「我碰了会怎么样。」「热敏反应膜，检测到非授权操作，零点三秒升温到八百度，里面的东西全毁。」 |

## 第三部分：24项全面扫描

### 结构类（必须避免）

1. 连续3段<60字（碎段失控）
2. 连续2段一句成段
3. 连续3段厚段（砖墙效应）
4. "一观点一段"等长切片
5. 标题：对仗式/冒号式/悬念党
6. 单独一段写"挑战与机遇并存""未来可期"

### 句式类（必须避免）

7. AI典型句式：「值得注意的是/不可否认/毋庸置疑/令人深思/引发关注」
8. 排比三段：「不仅…而且…更…」「既…又…还…」「首先其次再次最后」
9. bullet point 和列表
10. 全长句无短句顿挫，或全短句无长河感
11. 连续感叹号（每篇 <= 2个）

### 模板腔类（核心检测区）

12. 伪口语化：「拆一拆/拆解/梳理/剖析/聊一聊/盘一盘/捋一捋/划重点/敲黑板/说白了/本质上/归根结底」
13. 分析师讲解语姿：「把X拆完/说完/看完/理完，再/便/就Y」
14. AI关联句式堆叠：「一旦…就/只有…才/无论…都/随着…的/正是因为…所以」（>2为堆叠）
15. 戏剧化揭露：「扯下/撕下/揭下/掀开+遮羞布/面具/画皮/伪装/外衣」
16. 极值判断：「最X的地方在于/真正X的是/X之处在于/更X的是」（>1为堆叠）
17. 伪学术腔：「舆论场/话语场/权力场/宏大叙事/官方叙事/底层逻辑/赛道/闭环/抓手」
18. 判断式/定义式堆叠：「A是B/A不是B/所谓A即B」（>3为堆叠）
19. 二分对照壳：「不是A而是B/并非A而是B/不在于A而在于B」
20. 模糊归因：「专家认为/研究表明/有人指出」（无来源即降级或删）

### 语姿类（核心检测区）

21. 协作交流痕迹：「让我们/接下来/下面我将/希望这能帮助你」
22. 知识截止免责：「截至我的知识/作为AI模型」
23. 客服式谄媚：「很高兴/荣幸/感谢你的提问」
24. 新闻体开局（时间+地点+人物+事件）

## 第四部分：人类写作核心机制

### 机制一：叙事引力（核心驱动力）

> **所有文本必须围绕"未完成状态"运行**

每一段必须指向至少一个：
- 未确认的信息
- 未解决的冲突
- 未理解的现象
- 即将发生但尚未发生的变化

### 机制二：不均匀原则

> **人类写作 = 不均匀系统**

禁止任何稳定模式：
- ❌ 均匀节奏
- ❌ 均匀信息密度
- ❌ 均匀段落长度
- ❌ 均匀情绪推进

✅ 稳定可以极短（1句），混乱可以极长（多句）

### 机制三：信息密度呼吸

必须交替出现：
- **高密度**：动作/事件集中
- **低密度**：环境/感知描写
- **空白段**：停顿/无意义动作

### 机制四：注意力漂移规则

所有偏移必须来自：
- 感官变化（声音/光/温度）
- 身体行为（呼吸/动作/停顿）
- 环境变化（人群/物体/空间）
- 外部事件（打断/声音/冲突）
- 记忆闪回（短暂）

## 第五部分：五步操作法

### 第一步：结构层（决定性，必须优先）

1. 砍时间线过渡词（「然后」「接着」「之后」「于是」）
2. 打散整齐的列举顺序
3. 改问答式对话为信息倒灌

### 第二步：红线扫描

逐项检查11条快速硬门槛，命中即改。

### 第三步：禁用词替换

#### 一级禁用词（出现即替换）

| 类别 | 禁用词 | 替换为 |
|------|--------|--------|
| 情态类 | 仿佛、好像、犹如、宛若、一丝、一抹、些许、几分、隐约 | 删掉或具体描写 |
| 动作类 | 深吸一口气、缓缓、不禁、微微、轻轻、淡淡 | 具体动作或删掉 |
| 表情类 | 眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩 | 动作替代 |
| 心理类 | 心中一动、心头一震、心下了然、心中暗道 | 用行为展示 |
| 判断类 | 不容置疑、显而易见、毫无疑问 | 直接说事实 |
| 过渡类 | 突然、瞬间、不由自主、情不自禁 | 删或具体化 |

### 第四步：情绪外化（Show Don't Tell）

| 情绪 | ❌ 禁用 | ✅ 替换 |
|------|--------|--------|
| 紧张 | 他感到紧张 | 他攥紧了手里的纸杯，水洒出来 |
| 愤怒 | 愤怒在心中燃烧 | 他把筷子往桌上一拍 |
| 悲伤 | 一丝悲伤涌上心头 | 她低头搅着咖啡，搅了很久 |
| 害怕 | 恐惧笼罩了他 | 他的背贴在墙上，不敢动 |
| 失望 | 她感到失落 | "哦。"她把手机锁了屏 |
| 惊讶 | 瞳孔微微收缩 | 他张了张嘴，什么都没说出来 |

### 第五步：节奏打碎与结尾处理

**段落控制**：每段最多2-3句

**句长匹配场景**：
- 打斗/紧张：3-8字
- 对话：口语化
- 日常：8-15字
- 描写：不超过20字

**结尾处理**：
❌ 禁止的章尾：
- 总结性感悟
- 升华式感叹
- 哲理式收尾
- 伏笔式预告

✅ 正确的章尾：
- 用动作收尾
- 用对话收尾
- 用悬念收尾

## 第六部分：网文特有技法

### 网文节奏控制

1. **钩子密度**：每1000字至少2个悬念钩子
2. **爽点节奏**：「打脸」「反转」「升级」场景要有具体数据支撑
3. **代入感检查**：主角行为能被读者理解、共鸣、接受
4. **信息差控制**：读者已知信息要有效操控，制造情绪波动

### 对话优化

| 场景 | 技巧 |
|------|------|
| 冲突对话 | 口语化，加入语气词（"嗯""哦""行吧"） |
| 解释性对话 | 删掉，角色不会把自己的动机说清楚 |
| 紧张对话 | 用动作穿插（"她喝了口水。'然后呢？'"） |

### 主语锚定规则

| 位置 | 用谁 | 示例 |
|------|------|------|
| 新场景/新动作段开头 | 名字 | 陆远蹲下来，捡起一块碎片。 |
| 连续动作内（2-5段） | 省略 | 翻过来看接口（省略主语） |
| 动作段切换时 | 他/她 | 他回到货舱门边 |
| 关键情绪/转折点 | 名字 | 陆远愣了愣（用名字强化） |

### 人物人味检查

每章必须检查：
- [ ] 角色出声了吗（自言自语、发力喊声、嘀咕）
- [ ] 角色露情绪了吗（烦躁、松一口气、笑）
- [ ] 角色有停顿吗（歇口气、想一想、犹豫一下）
- [ ] 角色有身体反应吗（打了个哆嗦、抓脑袋、长舒一口气）

## 第七部分：系统化去AI三遍法

### Pass 1：去泛化（Strip Generic）

- 抽象情绪总结句 → 删或替换为具体动作
- 假深度句 → 删
- 意义膨胀 → 缩小到具体影响
- 工整对比句式 → 打散重写
- 装饰性形容词堆砌 → 白描
- 过度使用"于是""然而""此刻" → 删掉一半

### Pass 2：去书面化（Cut Professional Diction）

- 分析性用词（"机制""结构""逻辑""体系"在小说中）→ 日常表达
- 抽象名词滥用 → 直接说事
- 专业术语堆砌 → 只保留必要的，用白话解释
- 书面语连词（"于是乎""与此同时""从而""因而"）→ 删或口语化

### Pass 3：回人味（Restore Human Presence）

- 具体的感官细节（气味、温度、触感）
- 角色说话方式的区分（不同人不同语气）
- 节奏变化（长短句交错）
- 场景特有的记忆点

## 第八部分：量化指标

### AI味程度判定

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度 | <=5处/千字 | 6-15处/千字 | >15处/千字 |
| 连续排比段落 | <=2段 | 3-4段 | >=5段 |
| 平均段落句数 | <=3句 | 3-5句 | >5句 |
| 对话标签密度 | <=30% | 30-50% | >50% |

**综合判定**：取最高档位。任一指标达重度即按重度处理。

### 升级策略

| AI味程度 | 策略 |
|----------|------|
| 轻度 | Pass 1 + 红线检查 |
| 中度 | Pass 1 + Pass 2 + 红线 + 重点段落重写 |
| 重度 | 完整三遍 + 重点段落重写 |

## 第十部分：真人写作特征对比

| 维度 | 真人写法 | AI写法 |
|------|----------|--------|
| 段落长度 | 1-3句为主 | 每段4-6句，整齐均匀 |
| 对话标签 | 60%+无标签 | 几乎每句都有"说道/问道" |
| 情绪表达 | 动作展示 | 直接告诉 |
| 比喻 | 生活化 | 文学化 |
| 语气词 | "嗯""嘶""靠""行吧" | 几乎没有 |
| 省略 | 大量省略 | 面面俱到 |
| 排比 | 偶尔1-2个 | 连续3+个 |
| 结尾 | 动作/对话收尾 | 总结/升华/感慨 |
