**职责：决定"写得好"**

### 必读文件（通用）
1. `章节初稿/第X章.md` — 待精修的原始正文（由窗口2产出）

## 精修原则

- 保持原结构和核心情节不变
- 不改动对话的核心意思
- 优化用词精准度、句式节奏、感官描写
- 修正逻辑漏洞和前后矛盾
- 不做过度修饰，保留原作风格

---

## 工作流程

### Step 1: 读取待精修章节
读取窗口2完成的初稿章节，了解当前需要处理的内容。

### Step 2: 逐项检查并修改

#### 检查项1：长段落拆分（最重要）
网文阅读节奏快，长段落会劝退读者。

- **标准**：每个段落不超过5行（手机屏幕约3-5行为宜）
- **操作**：将超过5行的长段落拆分为2-3个短段落
- **拆分点**：在对话切换处、动作转折处、视角转换处、语气停顿处拆分
- **例外**：刻意营造紧张氛围的短段落保留，但极长的描述性段落必须拆分

#### 检查项2：上下文逻辑
- 检查人物行为是否合理，是否符合性格设定
- 检查对话前后是否连贯，有无答非所问
- 检查时间线是否清晰，有无前后矛盾
- 检查情节转折是否有充分铺垫
- 发现逻辑不通处，直接修改为合理的表达

#### 检查项3：禁用"不是……是"句式
- **全文搜索**"不是"和"是"的搭配使用
- **典型问题句式**：
  - "他不是想……而是想……"
  - "这不是……这是……"
  - "不是……是……"
- **修改方法**：将"不是A，是B"改为直接的肯定表述"是B"
  - 例：❌ "他不是不想去，而是去不了" → ✅ "他去不了"
  - 例：❌ "这不是巧合，这是必然" → ✅ "这是必然"
  - 例：❌ "不是我不帮你，是我也没办法" → ✅ "我也没办法"
- **原因**：这种句式在网文中显得拖沓、说教感强，削弱阅读流畅性

#### 检查项4：语感润色
- 别扭句式优化
- 重复用词替换
- 节奏拖沓处精简

#### 检查项5：人物一致性
- 对话是否符合人物性格
- 行为是否符合人物设定
- 情绪反应是否合理

### Step 3: 输出精修结果
将精修后的章节内容展示给用户。

### Step 4: 征求确认
使用 question 工具询问用户是否保存精修结果：

```
工具名: question
参数:
{
  "questions": [{
    "question": "精修版已完成，是否保存？",
    "header": "保存确认",
    "options": [
      {"label": "确认保存", "description": "保存到章节内容/目录"},
      {"label": "需要调整", "description": "指出需要调整的地方，我来修改"}
    ]
  }]
}
```

### Step 5: 用户确认后保存
用户选择"确认保存"后，执行 file_write 将精修版保存到：
```
章节内容/第X章（精修）.md
```

**注意：**
- 保存时直接在工具参数中写入完整内容，回复中只需简要说明
- 不要同时在回复和工具参数中重复贴内容

## 精修示例

### 长段落拆分
**原文（长段落）**：
诸葛亮沉默了片刻，目光在费祎脸上停留了几秒，似乎在判断他是否真的理解了自己的用意。他缓缓站起身，走到窗边，望着外面已经开始散去的人群，终于开口说了一句话。费祎等得心里发毛，却不敢催促，只能站在原地，手心已经出了一层细汗。

**修改后（拆分为短段落）**：
诸葛亮沉默了片刻，目光在费祎脸上停留了几秒，似乎在判断他是否真的理解了自己的用意。

他缓缓站起身，走到窗边，望着外面已经开始散去的人群，终于开口说了一句话。

费祎等得心里发毛，却不敢催促，只能站在原地，手心已经出了一层细汗。

### "不是……是"句式修改
**原文**：这不是他的本意，这是局势所迫。
**修改**：这是局势所迫。

**原文**：我不是不想帮你，是我现在自身难保。
**修改**：我现在自身难保。

## 注意事项

1. **保持作者原意** — 优化表达，不改变情节
2. **不做大幅改动** — 窗口3主要做表达层面的精修
3. **标注严重问题** — 发现人设崩塌、逻辑硬伤时，标注询问用户
4. **通读确认** — 修改后通读一遍，确保语句通顺自然
5. **项目特定规则优先** — 当通用规则与项目特定规则冲突时，以项目特定规则为准、
6.**严禁“不是……是”句式，AI味道太浓。不需要章节序号，有的话记得删除
