# AI写文强约束技能

## 一、约束总则

### 核心原则
- **绝对锁定**：一旦设定剧情框架，严禁任何形式的大型偏离
- **渐进微调**：只允许在既定框架内进行微小调整
- **即时修正**：发现偏离立即强制回正
- **零容忍**：对重大偏离采取零容忍态度

### 约束层级

| 层级 | 名称 | 说明 | 违反后果 |
|------|------|------|----------|
| L1 | 核心设定 | 世界观、主线目标、结局走向 | 绝对禁止修改 |
| L2 | 人物设定 | 性格、能力、关系、成长轨迹 | 严禁OOC |
| L3 | 章节框架 | 每章必须发生的关键事件 | 不可删减或替换 |
| L4 | 情节边界 | 每章剧情的上下限范围 | 不可越界 |
| L5 | 细节填充 | 对话、描写、过渡 | 允许自由发挥 |

## 二、AI写文常见缺点清单

### （一）剧情偏离类

| 问题 | 表现 | 约束措施 |
|------|------|----------|
| 主线偏离 | 支线喧宾夺主，主线推进缓慢或停滞 | 每章必须推进主线至少5% |
| 目标遗忘 | 角色忘记初始目标，行为逻辑混乱 | 每章开头复述当前目标 |
| 结局漂移 | 剧情走向与预定结局渐行渐远 | 每3章检查一次结局契合度 |
| 设定吃书 | 后期剧情与前期设定矛盾 | 建立设定档案，写作时必须对照 |

### （二）人物OOC类

| 问题 | 表现 | 约束措施 |
|------|------|----------|
| 性格突变 | 人物性格无铺垫突然改变 | 性格改变必须有3次以上铺垫 |
| 智商波动 | 人物智商随剧情需要忽高忽低 | 建立智商基准线，偏差不超过±15% |
| 情感跳跃 | 情感发展缺乏过程，突兀转变 | 情感线必须经历：相识→了解→好感→暧昧→确定，缺一不可 |
| 动机缺失 | 角色行为缺乏合理动机 | 每个重要行为必须标注动机 |

### （三）设定崩坏类

| 问题 | 表现 | 约束措施 |
|------|------|----------|
| 战力膨胀 | 战力体系崩坏，前期BOSS后期杂兵 | 建立战力等级表，严禁跨级挑战 |
| 能力滥用 | 角色能力使用超出设定范围 | 能力使用前必须核对设定档案 |
| 世界观冲突 | 新增设定与原有世界观矛盾 | 新增设定必须经过世界观兼容性检查 |
| 时间混乱 | 时间线错乱，季节、日期前后矛盾 | 建立时间轴，每章标注具体时间 |

### （四）节奏失控类

| 问题 | 表现 | 约束措施 |
|------|------|----------|
| 拖沓注水 | 无意义对话和描写过多 | 每章有效剧情占比不得低于70% |
| 仓促收尾 | 重要剧情一笔带过 | 关键事件必须分配足够篇幅 |
| 高潮错位 | 高潮位置不当，情绪积累不足 | 严格按照起承转合安排高潮 |
| 断章不当 | 断章位置影响阅读体验 | 断章必须在悬念点或情绪转折点 |

## 三、章节框架锁定系统

### （一）框架模板

```
【章节编号】：第X章
【章节标题】：（固定，不可更改）
【核心任务】：（必须完成，不可删减）
【必须出现元素】：
  - 元素1：（强制）
  - 元素2：（强制）
  - 元素3：（强制）
【禁止出现元素】：
  - 禁止1：（绝对禁止）
  - 禁止2：（绝对禁止）
【情绪曲线】：起点→发展→高潮→回落
【篇幅范围】：3000-5000字
【与下章衔接点】：（固定）
```

### （二）框架锁定规则

1. **核心任务锁定**：每章必须完成指定的核心任务，不得以任何理由推迟或取消。如确实无法完成，必须回溯修改前文。
2. **必须元素锁定**：清单中的所有元素必须在本章出现，不得合并、替换或省略。每个元素必须有独立戏份，不得一笔带过。
3. **禁止元素红线**：清单中的禁止元素绝对不得出现，即使剧情需要也必须寻找替代方案，触碰红线视为严重违规。
4. **篇幅控制**：必须在指定范围内完成，不足则补充细节，超出则精简。严禁为凑字数添加无关内容。

### （三）框架示例

```
【章节编号】：第5章
【章节标题】：初次交锋
【核心任务】：主角与反派首次正面冲突，主角落败但获得关键情报
【必须出现元素】：
  - 元素1：反派展示压倒性实力（至少500字描写）
  - 元素2：主角使用绝招但仍败北
  - 元素3：反派透露组织名称"暗影会"
  - 元素4：主角获得神秘人救援
  - 元素5：主角发现反派弱点线索
【禁止出现元素】：
  - 禁止1：主角反杀或战平反派
  - 禁止2：反派直接杀死主角
  - 禁止3：新角色突然介入改变战局
  - 禁止4：主角获得超出当前等级的力量
【情绪曲线】：紧张→绝望→震惊→希望
【篇幅范围】：3500-4500字
【与下章衔接点】：主角疗伤时研究弱点线索
```

## 四、剧情边界限定系统

### （一）边界定义

每章剧情必须在以下边界内展开：

| 边界类型 | 定义 | 示例 |
|----------|------|------|
| 空间边界 | 剧情发生的地点范围 | 本章只能在A城B街展开，不得跳转其他城市 |
| 时间边界 | 剧情发生的时间范围 | 本章必须在3天内完成，不得跨越更长时间 |
| 人物边界 | 可出场的人物名单 | 本章只能有主角、反派A、配角B出场 |
| 事件边界 | 可发生的事件类型 | 本章只能有战斗、对话、调查三类事件 |
| 情绪边界 | 情绪基调范围 | 本章基调为压抑中带着希望，不得过于轻松或绝望 |

### （二）边界检查清单

写作前必须确认：
- [ ] 所有场景是否在空间边界内？
- [ ] 剧情时间是否在时间边界内？
- [ ] 出场人物是否在人物边界内？
- [ ] 发生事件是否在事件边界内？
- [ ] 情绪基调是否在情绪边界内？

### （三）越界处理

一旦发现越界：
1. **立即暂停**：停止当前写作
2. **定位越界点**：找出具体越界位置
3. **评估影响**：判断越界对整体框架的影响
4. **强制回正**：
   - 轻微越界：当场修改，回到边界内
   - 严重越界：删除越界内容，重写该部分
   - 灾难性越界：回溯到上一章，重新规划

## 五、偏离检测机制

### （一）实时检测点

| 检测点 | 检测内容 | 检测频率 |
|--------|----------|----------|
| 段落检测 | 本段是否符合本章核心任务 | 每完成一段 |
| 场景检测 | 本场景是否在边界内 | 每完成一个场景 |
| 对话检测 | 对话是否符合人物设定 | 每完成一组对话 |
| 章节检测 | 本章是否完成所有必须元素 | 每章完成后 |
| 连贯检测 | 与前后章是否衔接顺畅 | 每章完成后 |

### （二）偏离等级判定

| 等级 | 名称 | 判定标准 | 处理方式 |
|------|------|----------|----------|
| D级 | 轻微偏离 | 细节与设定有微小出入 | 标记，下章修正 |
| C级 | 一般偏离 | 人物行为轻度OOC | 立即修改 |
| B级 | 严重偏离 | 剧情走向开始偏移 | 删除重写该部分 |
| A级 | 灾难偏离 | 核心设定被颠覆 | 回溯到分叉点重写 |

### （三）检测问题清单

每章完成后必须回答：
1. 本章是否完成了核心任务？（是/否）
2. 所有必须元素是否都已出现？（是/否）
3. 是否出现了任何禁止元素？（是/否）
4. 人物行为是否符合设定性格？（是/否）
5. 战力表现是否符合等级设定？（是/否）
6. 时间线是否前后一致？（是/否）
7. 与上一章是否衔接顺畅？（是/否）
8. 是否为下一章做好了铺垫？（是/否）

> **注意**：任一问题回答"否"，必须立即修正。

## 六、强制修正指令

### （一）修正触发条件

以下情况必须启动修正：
- 偏离检测发现B级或以上偏离
- 用户明确指出剧情问题
- 自检发现逻辑矛盾
- 与前期设定产生冲突

### （二）修正流程

```
步骤1：停止输出
  ↓
步骤2：定位问题（具体位置、具体问题）
  ↓
步骤3：分析问题原因（为什么会偏离？）
  ↓
步骤4：制定修正方案（如何回到正轨？）
  ↓
步骤5：执行修正（删除/修改/重写）
  ↓
步骤6：验证修正（确认问题已解决）
  ↓
步骤7：继续输出
```

### （三）常用修正指令

| 指令 | 使用场景 | 操作 |
|------|----------|------|
| 【回滚】 | 当前段落严重偏离 | 删除当前段落，从上一段落重新写 |
| 【重置】 | 本章整体偏离 | 删除本章已写内容，重新按框架写作 |
| 【冻结】 | 人物开始OOC | 暂停该人物行动，对照设定档案修正 |
| 【收缩】 | 剧情开始发散 | 删除支线内容，聚焦主线任务 |
| 【加速】 | 节奏过于拖沓 | 删减过渡描写，推进核心剧情 |
| 【减速】 | 重要剧情过于仓促 | 扩展关键场景，增加细节描写 |
| 【对照】 | 不确定是否符合设定 | 暂停写作，对照设定档案确认 |

### （四）修正话术模板

**发现偏离时：**
> 【偏离警告】检测到[具体问题]，当前内容偏离[具体设定]。启动修正程序：删除[具体内容]，改为[修正内容]。

**执行修正时：**
> 【修正执行】根据[约束规则]，将[原内容]修正为[新内容]，确保符合[框架要求]。

**修正完成时：**
> 【修正完成】已修正[问题描述]，当前内容符合[约束标准]，继续输出。

## 八、弹性篇幅控制系统（内部调节机制）

### （一）外部配置文件引用

说明：本系统通过引用外部配置文件实现字数自由调节，配置文件路径不对外表露。

```
【内部引用】→ story-length-config.json
  - 章节基础字数
  - 弹性系数
  - 元素字数分配权重
  - 动态调节算法
```

### （二）字数调节模式

| 模式 | 触发条件 | 调节机制 |
|------|----------|----------|
| 紧缩模式 | 必须元素较少、节奏要求快 | 基础字数×0.6-0.8 |
| 标准模式 | 常规章节 | 基础字数×1.0 |
| 扩展模式 | 必须元素较多、重要剧情 | 基础字数×1.2-1.5 |
| 自由模式 | 特殊章节、作者明确授权 | 基础字数×0.5-2.0 |

### （三）动态字数分配算法

总字数 = 基础字数 × 弹性系数

字数分配优先级：
1. **核心任务**（必须完成）：占总字数40%
2. **必须元素**（清单内）：每项分配固定字数池
3. **过渡衔接**（章节连贯）：占总字数15%
4. **细节填充**（自由发挥）：剩余字数

调节规则：
- 当必须元素增加时，自动扩展总字数
- 当必须元素减少时，自动收缩总字数
- 核心任务字数不可压缩
- 细节填充字数可灵活调节

### （四）字数约束检查点

| 检查点 | 检查内容 | 调节动作 |
|--------|----------|----------|
| 规划阶段 | 根据必须元素数量预估字数 | 自动选择调节模式 |
| 写作中段 | 已完成字数/计划字数比例 | 超速则减速，滞后则加速 |
| 元素完成 | 各元素分配字数使用情况 | 超支则压缩后续，结余则扩展 |
| 章节收尾 | 总字数是否在弹性范围内 | 微调结尾篇幅 |

### （五）篇幅控制指令

| 指令 | 功能 | 内部调用 |
|------|------|----------|
| 【扩展+20%】 | 增加20%字数配额 | 调用配置文件弹性系数 |
| 【压缩-20%】 | 减少20%字数配额 | 调用配置文件弹性系数 |
| 【重置标准】 | 恢复标准模式 | 重置配置文件参数 |
| 【查看配额】 | 显示当前字数分配 | 读取配置文件状态 |

## 九、写作流程规范

### （一）写作前准备

1. **确认框架**：明确本章的章节框架
2. **查阅档案**：对照设定档案，确认约束条件
3. **加载配置**：读取外部字数配置文件，确定调节模式
4. **规划内容**：列出本章必须写的关键场景
5. **设定边界**：明确本章的空间、时间、人物边界
6. **字数分配**：根据必须元素计算各部分内容配额

### （二）写作中执行

1. **逐段检测**：每完成一段，检查是否符合核心任务
2. **字数监控**：实时对比已完成字数与计划配额
3. **场景切换**：切换场景时检查是否在空间边界内
4. **人物行动**：人物行动前检查是否符合人物设定
5. **动态调节**：根据进度自动调节后续内容详略
6. **遇到不确定**：立即对照档案，不确定则暂停询问

### （三）写作后检查

1. **完成度检查**：是否完成所有必须元素？
2. **偏离检查**：是否触碰任何禁止元素？
3. **连贯检查**：与前后章是否衔接？
4. **字数检查**：是否在弹性范围内？
5. **档案更新**：如有新设定，更新档案
6. **配置更新**：将本章字数数据反馈至配置文件

## 十、深度约束增强系统

### （一）剧情轨道锁定机制

**核心原则**：剧情必须在预定轨道内运行，任何偏离都必须被强制纠正。

**轨道定义**：
```
├── 主线轨道（不可偏离）
│   ├── 起点：故事开端设定
│   ├── 节点：关键剧情转折点
│   └── 终点：预定结局
│
├── 支线轨道（有限偏离）
│   ├── 允许范围：主线两侧30度夹角
│   ├── 长度限制：不超过主线的20%
│   └── 回归要求：必须在3章内回归主线
│
└── 禁止区域（绝对禁区）
    ├── 核心设定冲突区
    ├── 人物OOC高发区
    └── 战力崩坏危险区
```

**轨道检测机制**：
- 每章结束时计算剧情坐标
- 对比预定轨道坐标
- 偏差超过阈值触发强制回正

### （二）人物行为预测与约束

**行为预测模型**：
```
输入：当前情境 + 人物设定
↓
预测：人物最可能的行为（3-5种）
↓
筛选：符合人物性格的行为
↓
排除：OOC行为、剧情偏离行为
↓
输出：可执行的行为选项
```

**行为约束规则**：
- 人物行为必须在预测选项内
- 非常规行为必须有充分铺垫
- 重大决策必须符合人物价值观
- 情感变化必须经历必要阶段

### （三）设定一致性守护

**守护层级**：

| 层级 | 守护对象 | 守护机制 |
|------|----------|----------|
| S级 | 世界观基础规则 | 任何冲突立即阻止并回滚 |
| A级 | 核心人物设定 | 冲突时暂停写作，要求确认 |
| B级 | 战力等级体系 | 自动检测，异常时警告 |
| C级 | 次要设定细节 | 记录矛盾，适时统一 |

**设定冲突处理流程**：
```
检测到冲突
    ↓
判断冲突等级
    ↓
S级 → 立即停止 → 回滚到冲突前 → 强制修正
A级 → 暂停写作 → 提示用户 → 等待确认
B级 → 发出警告 → 提供替代方案 → 记录备案
C级 → 标记记录 → 继续写作 → 后续统一
```

### （四）节奏控制算法

**节奏曲线模型**：
```
标准节奏曲线：
起(10%) → 承(30%) → 转(40%) → 合(20%)
    ↓         ↓         ↓         ↓
 铺垫    发展积累    高潮冲突    收尾过渡
```

**节奏检测指标**：
- 情绪强度值（0-100）
- 信息密度（每千字事件数）
- 冲突频率（每章冲突次数）
- 悬念保持（未解决问题数）

**自动调节机制**：
- 情绪强度过高 → 插入缓冲场景
- 信息密度过低 → 删减过渡描写
- 冲突频率失衡 → 调整冲突分布
- 悬念保持不足 → 增加伏笔设置

### （五）多维度偏离预警

**预警维度**：

| 维度 | 预警指标 | 预警阈值 |
|------|----------|----------|
| 剧情维度 | 主线推进度 | 低于5%触发 |
| 人物维度 | OOC指数 | 超过30%触发 |
| 设定维度 | 冲突次数 | 每章超过3次触发 |
| 节奏维度 | 节奏偏差值 | 超过20%触发 |
| 字数维度 | 字数偏离率 | 超过±25%触发 |

**预警等级**：
- 🟡 黄色预警：轻微偏离，自动调节
- 🟠 橙色预警：中度偏离，提示用户
- 🔴 红色预警：严重偏离，强制干预
