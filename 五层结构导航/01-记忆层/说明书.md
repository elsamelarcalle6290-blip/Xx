# 01-记忆层说明书

## 功能
这一层负责全局规则、工作区指针、项目级记忆和长期约束。它决定“默认怎么工作”，而不是“具体做什么能力”。

## 当前资源
- [AGENTS.md](/E:/Xx/AGENTS.md)：当前工作区总规则入口。
- [.claude/.webnovel-current-project](/E:/Xx/.claude/.webnovel-current-project:1)：当前小说项目指针。
- `C:\Users\Administrator\.codex\memories\`：Codex 用户级 memory 仓库。

## 使用方式
- 想改默认路由、默认工作流、写作规则：改这一层。
- 想切换当前小说项目：看 `.webnovel-current-project`。
- 想做长期记忆沉淀：用 `C:\Users\Administrator\.codex\memories\`。
