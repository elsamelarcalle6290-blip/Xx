# 百家号创作偏好与素材路径

## 1. 默认素材路径

- **首选路径**：用户提供的文章文档、Excel 文件、新闻链接集合或热点素材库。
- **默认执行逻辑**：当用户给出包含多条素材的文档时，不再反复询问主题、受众和字数，直接读取素材，筛选最适合百家号发布的 **15 条**，并生成 **15 篇百家号成稿**。
- **联网核验要求**：涉及最新时事、财经、产业、国际关系、政策、监管、公司、市场、人物职务、数据变化时，必须围绕同一事件进行联网核验，补足最新公开事实，但不能把文章写成资料汇编。

## 2. 备选素材路径

- **备选路径二：爆款对标文案**  
  用户直接提供以前写过的好文章、爆款文章、对标文案时，优先蒸馏其结构、节奏、开头方式、转折方式和收束方式。只能学习写法，不能照搬原句、段落和独特表达。

- **备选路径三：用户主题或初步想法**  
  用户只给出一个话题、方向或简短判断时，先自行联网查找同主题公开信息，再按百家号写法生成一篇完整文章。

## 3. 默认选题偏好

百家号优先筛选以下类型素材：

1. 财经市场、券商、A股、分红、监管、银行、利率、存款、基金、楼市等普通人能代入的钱袋子话题。
2. 产业链、供应链、稀土、科技、芯片、AI、算力、制造业、能源等能讲清现实影响的话题。
3. 国际关系、签证、制裁、外交表态、贸易摩擦、国家安全等有明确事实线和责任边界的话题。
4. 教育考试、公共安全、民生成本、出行风险等能落到普通人生活里的话题。

不优先选择纯猎奇、低俗、未经证实、只有情绪没有事实、无法核验来源的素材。

## 4. 百家号默认写法

百家号文章必须更像真人作者在讲一件具体事，不写成抽象观点稿。

推荐结构：

1. **开头抓情绪**：用一句短句切入普通人的直觉、担心或误会。
   - 例：券商股一有动静，市场就容易激动。
   - 例：签证这事看着只是递材料，真放到人员往来里，就不是一个小窗口的问题。

2. **马上对齐事实**：讲清谁做了什么、什么时候发生、涉及什么数字、规则、机构或处理结果。

3. **先承认合理点**：如果事件里确实有积极面、合理诉求或现实难处，要先承认。

4. **自然降温**：好事不等于风险消失，表态不等于落地，愿意谈不等于问题解决，龙头不等于不会跌。

5. **拆真正变量**：讲清真正影响结果的东西，比如利润质量、行业周期、成交量、执行力度、违规成本、供应链依赖、责任边界、审核流程、对等原则。

6. **落到普通人**：最后告诉读者该看什么、别上什么头、真正该担心或该期待的是什么。

## 5. 字数与标题

- 百家号正文不设死板字数，根据原文信息量、事件复杂度和核验资料决定篇幅。
- 信息量足的内容可以写长，信息量薄的内容不要硬凑；核心标准是讲清楚、讲完整、不要水。
- 不设死板上限，不为了凑字数重复观点。
- 每篇文章只输出 **1 个标题 + 正文**。
- 标题建议 **30-64 个中文字符**，要能直接区分标题和正文。
- 不输出 10 个备选标题，不标注标题类型，不输出写作角度、封面建议、摘要选择、大纲方案。

## 6. 发布稿输出格式

最终成稿默认格式：

```text
# 标题

**开头关键句**

正文第一段……

正文第二段……
```

正文可以使用自然段和少量加粗，但不要出现模板栏目名。

禁止出现：

- 引言
- 事件回顾
- 目前处理结果
- 事例分析
- 写在最后
- 那么小编想问
- 重点句
- 追问
- 写作角度
- 封面建议
- 素材称
- 原文提到
- 这篇内容提到
- 这件事看起来是一个新闻点
- 这类议题之所以容易引起讨论
- 公众真正关心的是
- 现实账
- 规则账
- 值得重新看

## 7. 事实底线

1. 不编造时间线、人物关系、官方表态、专家观点、网友评论、内部消息。
2. 不把未经证实的说法写成确定事实。
3. 不跨文章混用素材，每篇文章必须独立贴源。
4. 不为了爆款制造恐慌、仇恨、低俗攻击或投资诱导。
5. 财经、投资、市场类内容只能做信息解读和风险提醒，不能写“可以买、必涨、抄底、上车”等诱导性表达。
