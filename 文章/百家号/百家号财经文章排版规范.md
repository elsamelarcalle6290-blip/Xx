# 百家号财经文章排版规范

这份规范专门用于 **百家号财经类文章** 的最终排版。

目标很简单：

1. **读起来顺**
2. **手机上好扫读**
3. **重点能被一眼抓到**
4. **能直接复制到百家号后台使用**

## 一、总原则

1. 排版服务于阅读，不服务于花样
2. 财经文章要像“讲清楚一件事”，不要像“堆满资料的说明书”
3. 一篇文章最重要的是：
   - 开头能把人留下来
   - 中间能让人读得下去
   - 结尾能让人想评论
4. 排版必须帮助节奏，不要妨碍节奏

## 二、最终交付时的外层结构

如果是交给我来写，默认按下面顺序输出：

1. **5 个备选标题**
2. **1 段写作角度说明**
3. **正文**
4. **3 个封面关键词**

注意：

1. `标题区`、`角度说明`、`封面关键词` 可以保留适度的 Markdown 层次，方便查看
2. **正文必须尽量干净**，要以“可以直接复制进百家号后台”为标准
3. 正文里不要堆太多 Markdown 控制符，不要让排版痕迹重过内容本身

## 三、标题区排版

1. 备选标题一行一个
2. 不要在标题前加花哨符号
3. 不要用连续感叹号、连续问号
4. 标题本身优先简洁、顺口、信息明确

推荐样式：

```markdown
## 备选标题

1. 标题一
2. 标题二
3. 标题三
4. 标题四
5. 标题五
```

## 四、正文开头怎么排

百家号财经文章的开头，最怕两件事：

1. 一上来就大段铺背景
2. 一上来就端着讲大道理

默认写法：

1. **前 1 段**：直接抛最刺眼的矛盾点
2. **第 2 段**：翻译成普通人听得懂的话
3. **第 3 段**：把核心问题点出来

开头排版要求：

1. 前 3 段尽量都偏短
2. 每段最好 **40-100 字**
3. 最关键的判断句，可以单独成段
4. 不要开头三段全写成长段

## 五、正文段落长度

这是正文最重要的排版要求。

### 默认段长

1. 普通段落：**80-150 字**
2. 说明型段落：**60-120 字**
3. 强判断句：**单独成段，20-50 字也可以**
4. 特别复杂的解释段：尽量不要超过 **180 字**

### 禁忌

1. 不要一整屏只有一个大段
2. 不要连续 3 段都是特别长的大段
3. 不要为了显得“深度”，故意把句子拖很长

## 六、时间线排版

如果原素材本身有明确时间线，排版时要把时间顺序写清楚。

规则：

1. 时间点必须准确
2. 时间顺序必须稳定
3. 不要把前后顺序写乱
4. 不要为了流畅擅自补时间节点

适合的写法：

1. 放进自然段里顺着讲
2. 如果时间点很多，可以用 3-5 条短列表梳理

不适合的写法：

1. 把整篇文章写成流水账
2. 没有时间点却硬编时间线
3. 时间点太多太碎，影响阅读节奏

## 七、什么句子应该单独成段

以下内容优先单独成段：

1. 全文最核心的判断句
2. 最能引发讨论的追问句
3. 反差特别强的一句话
4. 从事实转入评论时的那一句转折句

比如：

“不是钱不想进来，而是很多人根本不敢进来。”

这种句子单独放一段，阅读效果会更好。

## 八、小标题怎么用

百家号财经文章**可以有小标题，但不要滥用**。

### 适合加小标题的情况

1. 文章超过 1500 字
2. 一篇文章里有 3 个以上分析层次
3. 盘点型文章需要分块
4. 政策 / 数据 / 行业逻辑比较复杂

### 不适合加小标题的情况

1. 文章本来就不长
2. 文章更适合一口气读完
3. 小标题一加，反而显得支离破碎

### 小标题要求

1. 要写成**信息型标题**
2. 不要写成空话标题
3. 尽量短，尽量直接

不推荐：

- 深度分析
- 值得注意的是
- 最后总结

推荐：

- 为什么钱很多，资金却不敢进场
- 回购看起来很猛，市场为什么没那么激动
- 高股息走强，背后其实是风格切换

## 九、加粗怎么用

加粗只能用来提醒重点，不能当装饰。

### 适合加粗的内容

1. 关键数字
2. 关键动作
3. 核心矛盾
4. 最重要的结论句里的关键词

### 每段控制

1. 每段最多加粗 **1-2 处**
2. 不要整段加粗
3. 不要连着几段都满屏加粗

### 原则

读者一眼扫过去，能看到重点，但不会觉得眼睛累。

## 十、列表怎么用

财经文章里，以下情况适合用列表：

1. 时间线
2. 数据对比
3. 多家公司盘点
4. 几个并列原因
5. 几个结论并排说明

### 列表要求

1. 一组列表最好控制在 **3-5 条**
2. 列表每条尽量短
3. 列表是为了让信息更清楚，不是为了凑形式

## 十一、数字排版

财经文章里，数字是抓眼球的重要工具。

规则：

1. 优先用 **阿拉伯数字**
2. 大数字优先写得直观
3. 同一篇文章里，数字写法要统一

例如：

- `10亿`、`100亿`、`174万亿`
- `6%`
- `4000点`

不要一会儿写阿拉伯数字，一会儿写中文大写数字，风格发散。

## 十二、正文里不要出现的东西

1. 不要出现花哨分隔符
2. 不要出现乱码
3. 不要出现一堆感叹号
4. 不要出现过强的营销语气
5. 不要出现“点这里”“私信我”“进群”“看主页”等导流语
6. 不要把正文写成公告摘抄
7. 不要把正文写成研报条目堆砌
8. 不要出现“引言”“事件回顾”“写在最后”“那么小编想问”这类模板化栏目名，除非用户明确要求保留

## 十三、15 篇批量写作时的排版去重

如果是一口气写 15 篇百家号财经文章，排版上要避免“像一个模子刻出来的”。

### 要主动错开

1. 开头句式
2. 小标题结构
3. 核心判断句的位置
4. 列表出现的频率
5. 结尾追问的语气

### 不要这样

1. 15 篇都开头三连问
2. 15 篇都先写“最值得注意的是”
3. 15 篇都在第 4 段单独放一句硬判断
4. 15 篇都用同一套“先讲现象，再讲原因，最后追问”的机械节奏

## 十四、默认收尾方式

收尾不要太满。

推荐收尾：

1. 回到普通人的利益感受
2. 回到市场真正奖惩的逻辑
3. 最后留一个值得讨论的问题

不要这样收尾：

1. 强行上价值
2. 强行喊口号
3. 强行给买卖建议
4. 靠低级阴阳怪气硬撑结尾

## 十五、最终自检

正式交付前，快速检查：

1. 开头三段是不是够短、够抓人
2. 有没有一整屏长段
3. 加粗是不是过量
4. 小标题是不是空话
5. 数字是不是醒目而统一
6. 结尾是不是还能引发讨论
7. 正文是不是能直接复制到百家号后台使用
